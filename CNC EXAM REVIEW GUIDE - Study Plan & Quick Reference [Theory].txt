DOMAIN 1: MACHINE COORDINATE SYSTEMS & SETUP (25%)
ENGLISH:
Topics:
□ Machine coordinate system (MCS) vs Work coordinate system (WCS)
□ MCS: Fixed by manufacturer, cannot change
□ WCS: Set by programmer for each workpiece
□ Edge finder tool - when used, how used, 6mm compensation
□ Dial Test Indicator (DTI) - alternative method for center finding
□ Finding X coordinate: Horizontal axis, left-right movement
□ Finding Y coordinate: Vertical axis (table), front-back movement  
□ Finding Z coordinate: Vertical machine axis (spindle), up-down
□ Perpendicularity compensation with six square
□ G54 through G59 offset codes (6 possible work offsets)
□ Work offset setting: Part zero point selection
□ Offset application timing: When and how points are set

РУССКИЙ:
Темы:
□ Координатная система станка (MCS) vs система координат заготовки (WCS)
□ MCS: Фиксирована производителем, не может изменяться
□ WCS: Устанавливается программистом для каждой заготовки
□ Edge finder – когда использовать, как использовать, компенсация 6 мм
□ Dial Test Indicator (DTI) – альтернативный метод поиска центра
□ Поиск координаты X: горизонтальная ось, движение влево-вправо
□ Поиск координаты Y: вертикальная ось (стол), движение вперёд-назад
□ Поиск координаты Z: вертикальная ось станка (шпиндель), движение вверх-вниз
□ Компенсация перпендикулярности с квадратом
□ Коды смещения G54–G59 (6 возможных рабочих смещений)
□ Установка рабочего смещения: выбор нулевой точки детали
□ Время применения смещения: когда и как устанавливаются точки

DOMAIN 2: SPEEDS, FEEDS & CALCULATIONS (20%)
ENGLISH:
Topics:
□ Spindle speed formula: N = (Vc × 1000) / (π × D)
□ Understand each variable: N (RPM), Vc (cutting speed), D (tool diameter)
□ Cutting speed (Vc) values by material:
   - Aluminum: 250-400 m/min
   - Steel: 100-200 m/min (much slower)
   - Cast iron: 80-150 m/min (same as steel)
   - Stainless steel: 80-150 m/min
   - Brass: 300+ m/min
   - Copper: 200-300 m/min
□ Feed rate formula: F = N × Z × FPT
□ Feed per tooth (FPT) concept: Feed per each cutting flute
□ Flute count impact: 2-flute vs 3-flute vs 4-flute difference
□ When to use each flute count (2 for plunging, 4 for side milling)
□ Material Removal Rate (MRR): Productivity measure
□ Tool coatings: TiN, TiAlN, Cobalt (improve speed 10-20%)
□ Cutting speed adjustments by operation (facing, slotting, shoulder)

РУССКИЙ:
Темы:
□ Формула скорости шпинделя: N = (Vc × 1000) / (π × D)
□ Понимание каждой переменной: N (об/мин), Vc (скорость резания), D (диаметр инструмента)
□ Значения скорости резания (Vc) по материалам:
   - Алюминий: 250–400 м/мин
   - Сталь: 100–200 м/мин (намного медленнее)
   - Чугун: 80–150 м/мин (как сталь)
   - Нержавейка: 80–150 м/мин
   - Латунь: 300+ м/мин
   - Медь: 200–300 м/мин
□ Формула подачи: F = N × Z × FPT
□ Концепция подачи на зуб (FPT): подача на каждую режущую канавку
□ Влияние количества канавок: различия 2-зубцовой vs 3-зубцовой vs 4-зубцовой
□ Когда использовать каждое количество зубцов (2 для погружения, 4 для боковой фрезеровки)
□ Скорость удаления материала (MRR): мера производительности
□ Покрытия инструмента: TiN, TiAlN, Cobalt (улучшают скорость на 10–20%)
□ Корректировка скорости резания по операциям (торцевание, паз, плечо)

DOMAIN 3: PROGRAM STRUCTURE & G-CODES (25%)
ENGLISH:
Topics:
□ Complete program structure template (10 stages)
□ Program numbering: O prefix (O00001-O99999 format)
□ Safety codes at startup:
   - G17 (XY plane selection)
   - G20 or G21 (Inch or Metric units)
   - G40 (Cancel diameter offset)
   - G49 (Cancel height offset)
   - G80 (Cancel cycles)
   - G90 (Absolute positioning mode)
□ Tool selection: T codes (T01, T02, etc.)
□ Work offset selection: G54-G59 codes
□ Tool length offset: H codes with G43 application
□ Movement codes:
   - G00 (Rapid positioning, fastest)
   - G01 (Linear interpolation, controlled feed)
   - G02 (Clockwise arc)
   - G03 (Counter-clockwise arc)
□ Spindle control:
   - S code: Spindle speed in RPM
   - M03: Start spindle clockwise
   - M04: Start spindle counter-clockwise
   - M05: Stop spindle
□ Coolant control:
   - M08: Coolant on
   - M09: Coolant off
□ Program end:
   - M02: End program (spindle continues)
   - M30: End program (spindle stops, reset)

РУССКИЙ:
Темы:
□ Полная структура программы (10 этапов)
□ Нумерация программ: префикс O (формат O00001–O99999)
□ Коды безопасности при запуске:
   - G17 (выбор плоскости XY)
   - G20 или G21 (дюймы или метрические единицы)
   - G40 (отмена компенсации диаметра)
   - G49 (отмена компенсации высоты)
   - G80 (отмена циклов)
   - G90 (режим абсолютного позиционирования)
□ Выбор инструмента: коды T (T01, T02 и т.д.)
□ Выбор рабочего смещения: коды G54–G59
□ Смещение по длине инструмента: коды H с применением G43
□ Коды движения:
   - G00 (быстрое позиционирование, самое быстрое)
   - G01 (линейная интерполяция, контролируемая подача)
   - G02 (окружность по часовой)
   - G03 (окружность против часовой)
□ Управление шпинделем:
   - S код: скорость шпинделя в об/мин
   - M03: запуск шпинделя по часовой
   - M04: запуск шпинделя против часовой
   - M05: остановка шпинделя
□ Управление охлаждением:
   - M08: охлаждение включено
   - M09: охлаждение выключено
□ Конец программы:
   - M02: конец программы (шпиндель продолжает вращение)
   - M30: конец программы (шпиндель останавливается, сброс)

FORMULA 1: SPINDLE SPEED CALCULATION
ENGLISH:
N = (Vc × 1000) / (π × D)

Where:
- N = Spindle speed in RPM
- Vc = Cutting speed for material (m/min) [CHECK MATERIAL TABLE]
- D = Tool diameter in millimeters
- π = 3.14159 (constant)

EXAMPLE:
Material: Aluminum (Vc = 300 m/min)
Tool: 10mm end mill
N = (300 × 1000) / (3.14159 × 10)
N = 300,000 / 31.4159
N = 9,549 RPM → Set 9,500 RPM on machine

РУССКИЙ:
N = (Vc × 1000) / (π × D)

Где:
- N = Скорость шпинделя в об/мин
- Vc = Скорость резания для материала (м/мин) [СМОТРЕТЬ ТАБЛИЦУ МАТЕРИАЛОВ]
- D = Диаметр инструмента в миллиметрах
- π = 3.14159 (константа)

ПРИМЕР:
Материал: алюминий (Vc = 300 м/мин)
Инструмент: торцевая фреза 10 мм
N = (300 × 1000) / (3.14159 × 10)
N = 300,000 / 31.4159
N = 9,549 об/мин → установить 9,500 об/мин на станке

PRACTICE PROBLEMS / ЗАДАЧИ НА ПРАКТИКУ:
1. Steel, 8mm tool: Vc=150, N = ? / Сталь, 8 мм, Vc=150, N = ?
2. Aluminum, 12mm tool: Vc=350, N = ? / Алюм, 12 мм, Vc=350, N = ?
3. Cast iron, 6mm tool: Vc=100, N = ? / Чугун, 6 мм, Vc=100, N = ?

---

FORMULA 2: FEED RATE CALCULATION
ENGLISH:
F = N × Z × FPT

Where:
- F = Feed rate in mm/min (what you enter in CNC program)
- N = Spindle speed in RPM [FROM FORMULA 1]
- Z = Number of cutting flutes/teeth on tool
- FPT = Feed per tooth in mm (typical 0.05-0.2 depending on tool/material)

EXAMPLE:
Spindle speed: 9,500 RPM
Flutes: 2-flute tool
Feed per tooth: 0.1 mm
F = 9,500 × 2 × 0.1 = 1,900 mm/min → Set 1,900 mm/min in program

РУССКИЙ:
F = N × Z × FPT

Где:
- F = Подача в мм/мин (что вы вводите в программу CNC)
- N = Скорость шпинделя в об/мин [ИЗ ФОРМУЛЫ 1]
- Z = Количество режущих канавок на инструменте
- FPT = Подача на зуб в мм (обычно 0.05–0.2 в зависимости от инструмента/материала)

ПРИМЕР:
Скорость шпинделя: 9,500 об/мин
Канавки: 2-зубцовой инструмент
Подача на зуб: 0.1 мм
F = 9,500 × 2 × 0.1 = 1,900 мм/мин → установить 1,900 мм/мин в программе

PRACTICE PROBLEMS / ЗАДАЧИ:
1. 8,000 RPM, 4-flute, 0.15mm FPT: F = ?
2. 5,000 RPM, 2-flute, 0.1mm FPT: F = ?
3. 12,000 RPM, 3-flute, 0.08mm FPT: F = ?

---

FORMULA 3: MATERIAL REMOVAL RATE (MRR)
ENGLISH:
MRR = Axial D × Radial D × Feed (mm³/min)
Or: MRR = (Ap × Ae × F) / 1000 in cm³/min
(This shows productivity/efficiency)

Where:
- Ap = Axial depth (Z-direction depth per pass)
- Ae = Radial depth (X/Y horizontal step-over)
- F = Feed rate

INTERPRETATION:
- Higher MRR = More material removed = Higher productivity
- Tool coatings increase speed → Increase MRR 10-20%
- But only if machine spindle and rigidity support it

РУССКИЙ:
MRR = Осевая глубина × Радиальная глубина × Подача (мм³/мин)
Или: MRR = (Ap × Ae × F) / 1000 в см³/мин
(показывает производительность/эффективность)

Где:
- Ap = Осевая глубина (глубина по оси Z за проход)
- Ae = Радиальная глубина (шаг по X/Y)
- F = Подача

ИНТЕРПРЕТАЦИЯ:
- Выше MRR = больше удалено материала = выше производительность
- Покрытия инструмента увеличивают скорость → увеличивают MRR на 10–20%
- Но только если шпиндель и жёсткость станка это поддерживают

FLUTE SELECTION LOGIC / ЛОГИКА ВЫБОРА КАНАВОК:

2-FLUTE / 2-ЗУБЦОВОЙ:
EN: Used for plunging, more chip evacuation space, larger flutes = lower feed rate, 
    typically FPT = 0.05-0.1mm
RU: Используется для погружения, больше пространства для вывода стружки, 
    большие канавки = низкая подача, обычно FPT = 0.05–0.1 мм

3-FLUTE / 3-ЗУБЦОВОЙ:
EN: Balanced option, can do side milling and plunging, medium FPT = 0.08-0.15mm
RU: Сбалансированный вариант, подходит для боковой фрезеровки и погружения, 
    средняя FPT = 0.08–0.15 мм

4-FLUTE / 4-ЗУБЦОВОЙ:
EN: Used for continuous side milling, more flutes = higher feed rate, 
    finer finish = FPT = 0.10-0.2mm, NOT good for plunging
RU: Для длительной боковой фрезеровки, больше зубцов = выше подача, 
    тонкая отделка = FPT = 0.10–0.2 мм, НЕ подходит для погружения

KEY DECISION / КЛЮЧЕВОЕ РЕШЕНИЕ:
"2 for plunging, 4 for side milling" / "2 для погружения, 4 для боковой фрезеровки"

G-CODE REFERENCE (Test List) / СПРАВОЧНИК G-КОДОВ:

G-Codes (Motion) / G-коды (движение):
G00 = Rapid / Быстрое позиционирование (fastest, no cutting / быстро, без реза)
G01 = Linear feed / Линейная подача (controlled speed, cutting / контролируемо)
G02 = Clockwise arc / Окружность по часовой (CW when viewing above)
G03 = Counter-clockwise arc / Окружность против часовой (CCW)
G17 = XY plane / плоскость XY (most common / обычный)
G20 = Inch units / единицы дюймы
G21 = Metric units / метрические (standard in most countries / стандарт)
G40 = Cancel diameter offset / отмена компенсации (STARTUP CODE / КОД ЗАПУСКА)
G43 = Apply tool length offset / применить смещение (with H code)
G49 = Cancel tool length offset / отмена смещения (STARTUP CODE)
G54-G59 = Work offset codes / рабочее смещение (select which offset / выбрать)
G80 = Cancel automatic cycles / отмена циклов (STARTUP CODE)
G90 = Absolute positioning mode / абсолютное (STARTUP CODE - most important / главный)

M-Codes (Miscellaneous) / M-коды (прочие):
M02 = End program / конец (spindle keeps running / шпиндель крутится)
M03 = Start spindle clockwise / запуск по часовой (CW)
M04 = Start spindle counter-clockwise / запуск против часовой (CCW)
M05 = Stop spindle / остановка
M08 = Coolant on / охлаждение вкл
M09 = Coolant off / охлаждение выкл
M98 = Call sub-program / вызвать подпрограмму (with P for number, L for repeat)
M99 = Return from sub-program / возврат из подпрограммы
M30 = End program / конец (reset everything / сброс всего)

TYPE 1: CALCULATION PROBLEMS / ТИП 1: РАСЧЁТНЫЕ ЗАДАЧИ
ENGLISH:
Q: "You have aluminum (Vc=300 m/min), 10mm tool, 2 flutes, 0.1mm FPT. 
    Calculate spindle speed and feed rate."
A: N = (300 × 1000)/(3.14 × 10) = 9,549 RPM
   F = 9,549 × 2 × 0.1 = 1,909 mm/min

РУССКИЙ:
В: "Алюминий (Vc=300 м/мин), 10 мм, 2 канавки, 0.1 мм FPT. 
    Рассчитайте скорость и подачу."
О: N = (300 × 1000)/(3.14 × 10) = 9,549 об/мин
   F = 9,549 × 2 × 0.1 = 1,909 мм/мин

TYPE 5: THEORY QUESTIONS / ТИП 5: ТЕОРЕТИЧЕСКИЕ ВОПРОСЫ
ENGLISH:
Q: "Why is flute count important in feed rate calculation?"
A: "More flutes = higher feed rate. Number of flutes × RPM determines how many 
    cutting edges engage per minute"

РУССКИЙ:
В: "Почему количество канавок важно для подачи?"
О: "Больше канавок = выше подача. Количество × об/мин = сколько режущих кромок
    в минуту"

PRACTICE / ПРАКТИКА:
Explain concepts in English and Russian / Объясните на обоих языках

TYPE 6: FORMULA APPLICATION (No Numbers) / ТИП 6: ПРИМЕНЕНИЕ ФОРМУЛ
ENGLISH:
Q: "If cutting speed increases but tool diameter stays same, does spindle 
    speed increase or decrease?"
A: N = (Vc × 1000)/(π × D) - if Vc increases, N increases (same denominator)

РУССКИЙ:
В: "Если скорость резания растёт, а диаметр нет, то об/мин растёт или падает?"
О: N = (Vc × 1000)/(π × D) – если Vc растёт, то N растёт

PRACTICE / ПРАКТИКА:
Reasoning about formula relationships / Рассуждайте о связях формул

TYPE 7: PRACTICAL DECISION MAKING / ТИП 7: ПРАКТИЧЕСКИЕ РЕШЕНИЯ
ENGLISH:
Q: "You're cutting steel with a 4-flute tool. Feed rate seems jerky. 
    What might be wrong?"
A: Could be: feed rate too high, cutting speed too high, tool dull, depth too deep
   Need to evaluate and adjust feed/speed

РУССКИЙ:
В: "Режете сталь 4-зубцовой фрезой. Подача рывками. Что не так?"
О: Может быть: подача высока, скорость высока, фреза тупая, глубина большая
   Нужно проверить и отрегулировать

PRACTICE / ПРАКТИКА:
Troubleshoot common problems / Решайте типичные задачи
