## 🎯 Обзор проекта

Этот проект создан студентом CNC программирования для помощи русскоязычным учащимся в освоении станков с ЧПУ. Материалы охватывают:

- ✅ **Теорию CNC** от базовых концепций до продвинутых техник
- ✅ **Практические G-коды** для симулятора SSCNC и станков HAAS
- ✅ **Упражнения MasterCam** для 2D и 3D программирования
- ✅ **Подготовку к экзаменам** с ответами и примерами
- ✅ **Математические расчеты** для CNC операций

### 🌟 Особенности

- 📖 **Полностью на русском языке** - все уроки, комментарии и инструкции
- 🎓 **Структурированный подход** - от простого к сложному (Lesson 3 - Lesson 18)
- 💻 **Готовые G-коды** - протестированные программы для практики
- 🔍 **Подробные объяснения** - каждый код с комментариями
- 📝 **Экзаменационные материалы** - реальные вопросы и ответы

## 🚀 Быстрый старт

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/ВАШ-USERNAME/CNC-Programming.git
cd CNC-Programming
```

### 2️⃣ Начните с теории

Откройте файл `3] CNC Recoded Theory TXT/README.txt` для понимания структуры теоретических материалов.

**Рекомендуемый порядок изучения:**
1. Начните с `1] Lessons [Theory]/CNC EXAM REVIEW GUIDE` - краткий обзор всех тем
2. Изучите уроки по порядку: `Lesson 3` → `Lesson 18`
3. Практикуйтесь с кодами из `1] SSCNC Simulator/`
4. Переходите к реальным G-кодам из `7] Work G-Codes [HAAS]/`

### 3️⃣ Практика в симуляторе

- Установите **SSCNC Simulator** (инструкция в `1] SSCNC Simulator/START SSCNC.txt`)
- Откройте упражнения из папок `Lesson 13-18`
- Запустите коды в симуляторе для визуализации

### 4️⃣ Подготовка к экзамену

Перед экзаменом используйте:
- `2] Exam Preparation/EXAM ANSWERS - Final.txt`
- `3] Key Points & Quick Reference/Важные моменты по CNC.txt`

## 📖 Основные разделы

### 🎓 Теория CNC

**Папка:** `3] CNC Recoded Theory TXT/1] Lessons [Theory]/`

| Урок | Тема | Описание |
|------|------|----------|
| **Lesson 3** | Work Offsets & Compensation | Рабочие смещения, компенсация инструмента |
| **Lesson 6** | Speeds, Feeds & Calculations | Формулы скорости шпинделя и подачи |
| **Lesson 7** | Program Structure & G-Codes | Структура программы, G-коды и M-коды |
| **Lesson 10** | Measurement Devices | Edge Finder, DTI, нулевые точки |
| **Lesson 11** | Cutting Tools | Характеристики инструмента, покрытия |
| **Lesson 13** | Verification & Depth Strategies | Верификация и стратегии резания |
| **Lesson 14** | Inside Outside Profiling | Контурная обработка |
| **Lesson 17** | Drills & Boring | Сверление и расточка |
| **Lesson 18** | Subprograms | Подпрограммы и управление |

- **Face Milling** - Торцевое фрезерование
- **Job Phases** - Многоэтапная обработка
- **R-Top Signature** - Подписание деталей
- **Комбинированные программы** - Полный цикл обработки

### 🎨 MasterCam проекты

**Папка:** `4] MasterCam/`

- 2D чертежи для практики

## 🛠️ Как использовать

### Для студентов

1. **Изучайте теорию последовательно** - каждый урок строится на предыдущем
2. **Практикуйтесь в симуляторе** - запускайте каждый код, понимайте его работу
3. **Добавляйте комментарии** - записывайте свои наблюдения прямо в коды
4. **Задавайте вопросы** - используйте Issues для обсуждений

### Для преподавателей

- Материалы можно использовать как дополнение к основному курсу
- Структура позволяет адаптировать содержание под программу
- G-коды протестированы и готовы к использованию на уроках

### Типичный рабочий процесс

```
📚 Читаю теорию (Lesson X)
    ↓
💻 Смотрю пример G-кода
    ↓
🔧 Запускаю в SSCNC Simulator
    ↓
📝 Анализирую и делаю заметки
    ↓
✅ Пробую модифицировать код
    ↓
🎯 Перехожу к следующему уроку
```
