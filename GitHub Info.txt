Для сброса сохраненных паролей >>> Powershell / CMD >>> git config --global --unset credential.helper

Для проверки: git config --global credential.helper если ничего не выводит значит удалились


1️⃣ Что делает

Git может запоминать логины и токены для GitHub (или других Git-серверов), чтобы не спрашивать каждый раз при git push или git pull.

Для этого используется credential helper — встроенный инструмент Git, который хранит данные для аутентификации.

Команда --unset credential.helper удаляет эту настройку и Git больше не будет использовать сохранённые креды.



git config	Изменяет или показывает настройки Git
--global	Применяет настройку ко всем репозиториям на этом ПК
--unset	Убирает указанную настройку
credential.helper	Настройка, отвечающая за хранение логинов/паролей
