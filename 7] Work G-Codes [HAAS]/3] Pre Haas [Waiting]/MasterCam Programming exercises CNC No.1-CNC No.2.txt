План работ в Mastercam для предварительного выравнивания заготовки

Исходная заготовка:
X102.35 Y51.2 Z25.8

Желаемый конечный размер детали:
X100 Y48 Z24

Важно:
Этот план ниже для предварительного выравнивания, как ты описал.
После выполнения 4 программ размеры станут X101 Y50 Z25.
До финала X100 Y48 Z24 останется снять еще:
по X: 1.0 мм, по Y: 2.0 мм, по Z: 1.0 мм.

Порядок создания и выполнения 4 G-code файлов

Итоговый порядок:
1. G-code 1: FaceMill сверху и с переворотом снизу, по 0.4 и 0.4.
2. G-code 2: Endmill Flat, уменьшить X срезом по Y на 0.85.
3. G-code 3: Endmill Flat, уменьшить X срезом по Y на 0.5.
4. G-code 4: Endmill Flat, уменьшить Y срезом по Y на 0.6 с двух сторон.
	В твоей установке материал ставится так, что этот съем идет именно по Y с двух сторон.

После этих 4 G-code должен получиться предварительный размер:
X101 Y50 Z25.

1. G-code No.1: Face Mill по Z, первая сторона 0.4 и вторая сторона 0.4
1.1. Операция: Face Mill.
1.2. Настроить проход на съем 0.4 мм с первой стороны.
1.3. Обработать первую сторону.
1.4. Перевернуть заготовку.
1.5. Тем же Face Mill снять 0.4 мм со второй стороны.
1.6. Контроль после двух сторон:
Z: 25.8 - 0.4 - 0.4 = 25.0
Ожидаемо: X102.35 Y51.2 Z25.0

Настройки и порядок для Endmill Flat (после FaceMill)
1. Сначала выбрать операцию Mastercam Contour.
2. Инструмент: Flat End Mill 20 mm.
2.1. Tool settings:
Feed rate: 150
Spindle speed: 1200
Галочка: Force tool change
3. В Cut Parameters:
Compensation type: Computer
Compensation direction: Left (если инструмент идет справа от контура, а снимаем слева)
Tip comp: Tip
Contour type: 2D
4. Подтвержденный рабочий пресет для бокового среза:
Tool diameter: Endmill Flat 20.0 mm.
Depth Cuts:
Max rough step: 0.0
# Finish cuts: 0
Finish step: 0.0
Depth Cuts можно не включать, если по глубине срезается вся плоскость/стенка сразу,
а не до конкретной глубины в несколько шагов по Z.
Lead In/Out: ничего не менять.
Break Through: выключен.
Multi Passes: включать, если нужно разделить боковой съем на несколько проходов.
Rough Number = количество проходов.
Rough Spacing = шаг между проходами.
Если Rough Spacing = 0.0, инструмент может повторять полный съем до финальной цепочки
(например, полный съем 0.85 в каждом проходе).
Проверенный рабочий вариант для съема 0.85 в 3 прохода:
Rough Number: 3
Rough Spacing: 0.2
Finish Number: 0
Finish Spacing: 0.0
Если Finish passes не используются (Finish Number = 0),
можно снять галочку Apply to all finish passes.
Отдельные значения Feed rate и Spindle speed для чистовых проходов
имеют смысл, когда Finish passes включены.
Tabs: выключен.
Linking Parameters:
All values Absolute
Clearance: 50.0
Retract: 25.0
Feed plane: 10.0
Top of stock: 0.0
Depth: -30.0
Почему Depth -30.0:
длина режущей кромки 40.0 mm, поэтому Depth -30.0 дает достаточный заход, чтобы срезать боковую стенку по высоте.
5. Как задать боковую глубину перед построением траектории:
сначала открыть Contour (это базовая операция для боковой резки)
Wireframe > Offset
смотреть сверху и сместить линию влево на нужную величину съема
после этого идти в Parameters > Toolpath Type > Chain geometry
удалить старую цепочку если она уже есть
нажать на значок мыши для выбора
выбрать новую offset-линию как текущую геометрию
6. Смысл этого шага:
Offset создает новую контрольную линию для нужного бокового съема
Chain geometry привязывает траекторию именно к этой линии
так ты заранее видишь, где будет идти срез по X или Y

2. G-code No.2: уменьшение длины X на 0.85 (проход вдоль Y)
2.1. Операция: Flat End Mill 20 mm.
2.1.1. Перед построением траектории сделать Wireframe > Offset и сместить линию на нужную величину съема по X.
2.1.2. Затем в Parameters > Toolpath Type > Chain geometry удалить старую цепочку и выбрать новую offset-линию.
2.2. В Cut Parameters выставить:
Compensation type: Computer
Compensation direction: Left
Tip comp: Tip
Contour type: 2D
2.3. Обработать одну боковую сторону: проход вдоль Y, съем по X = 0.85 мм.
2.4. Контроль после операции:
X: 102.35 - 0.85 = 101.50
Ожидаемо: X101.50 Y51.2 Z25.0

3. G-code No.3: уменьшение длины X на 0.5 со второй стороны (проход вдоль Y)
3.1. Перевернуть заготовку на противоположный бок по X.
3.2. Операция: Flat End Mill 20 mm.
3.2.1. Перед построением траектории сделать Wireframe > Offset и сместить линию на нужную величину съема по X.
3.2.2. Затем в Parameters > Toolpath Type > Chain geometry удалить старую цепочку и выбрать новую offset-линию.
3.3. В Cut Parameters оставить те же настройки:
Compensation type: Computer
Compensation direction: Left
Tip comp: Tip
Contour type: 2D
3.4. Снять 0.5 мм (проход вдоль Y, съем по X).
3.5. Контроль после операции:
X: 101.50 - 0.50 = 101.00
Ожидаемо: X101.00 Y51.2 Z25.0

4. G-code No.4: уменьшение ширины Y по 0.6 с двух сторон (проход вдоль X)
4.1. Операция: Flat End Mill 20 mm.
4.1.1. Перед построением траектории сделать Wireframe > Offset и сместить линию на нужную величину съема по Y.
4.1.2. Затем в Parameters > Toolpath Type > Chain geometry удалить старую цепочку и выбрать новую offset-линию.
4.2. В Cut Parameters оставить:
Compensation type: Computer
Compensation direction: Left
Tip comp: Tip
Contour type: 2D
4.3. Снять 0.6 мм с первой стороны: проход вдоль X, съем по Y.
4.4. Перевернуть заготовку на противоположный бок по Y.
4.5. Снять 0.6 мм со второй стороны: проход вдоль X, съем по Y.
4.6. Контроль после операции:
Y: 51.2 - 0.6 - 0.6 = 50.0
Ожидаемо: X101.00 Y50.00 Z25.0

Итог после 4 G-code файлов (предварительное выравнивание)
X101.00 Y50.00 Z25.0

Что дальше до финального размера X100 Y48 Z24
1. Снять еще 1.0 мм по X (обычно по 0.5 с каждой стороны или по стратегии основной обработки).
2. Снять еще 2.0 мм по Y (обычно по 1.0 с каждой стороны или по стратегии основной обработки).
3. Снять еще 1.0 мм по Z (Face Mill или в основной операции по высоте детали).

Рекомендация по контролю на каждом шаге
1. После каждой операции проверять фактический размер штангенциркулем/микрометром.
2. Перед переворотом всегда подтверждать базу и ноль детали.
3. В Mastercam делать Verify/Backplot перед постпроцессингом каждого файла.
4. Имена файлов сделать понятными:
No1_FaceMill_Z_0p4x2.nc
No2_X_minus_0p85.nc
No3_X_minus_0p5.nc
No4_Y_minus_0p6x2.nc
