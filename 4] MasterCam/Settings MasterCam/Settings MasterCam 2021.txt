Рекомендация
------------------------------
Чертеж детали лучше располагать с левой стороны от центра XYZ, например X = -100, Y = 50. Это удобно, потому что обычно с левой стороны стоят лазерные сенсоры для поиска нуля и контроля положения заготовки.

==============================
Mastercam 2021: одна шпаргалка для Face Mill и Contour
==============================

0. Общий порядок работы
-----------------------
1. Открыть Mastercam 2021.
2. Включить колонку Toolpaths через меню View.
3. Выбрать станок: Machine > Mill > GENERIC HAAS 3 - AXIS VMC MM.
4. Построить геометрию детали.
5. Открыть Machine Group Properties.
6. Настроить Files, Tool Settings и Stock Setup.
7. Добавить операцию Face Mill для обработки плоскости.
8. Добавить операцию Contour для боковой резки.
9. Перед постпроцессингом проверить траекторию в Backplot или Verify.

1. Общие настройки станка
--------------------------
Files
- Выбрать модель станка HAAS.
- Включить Output operation comments to NC.
- Включить Output machine name to NC.

Tool Settings (Дефолтные значения - которые будут задаваться автоматически для Tools)
- Spindle speed: 1200.0
- Feed rate: 140.0
- Retract rate: 150.0
- Plunge rate: 100.0
- Включить Adjust feed on arc move.
- Minimum arc feed: 125.0
- Assign tool numbers sequentially.
- Warn of duplicate tool numbers.
- Use tool’s step, peck, coolant.
- Override defaults with modal values.
- Clearance height.
- Retract height.
- Feed plane.
- Start sequence number: 1.0
- Increment: 1.0

Stock Setup
- Shape: Rectangular.
- Bounding box: Origin по центру или с левого угла.
- Size: X = 103, Y = 51, Z = 25.7.
- Если удобнее работать от левого нижнего угла, можно задать X = -100, Y = 0.

2. Face Mill для плоской обработки
----------------------------------
Tool
- Tool: Face Mill.
- Diameter: 63 mm.
- Feed rate: 180.
- RPM: 1200.
- Force tool change.

Cut Parameters
- Style: One pass.
- Stock to leave on floors: 0.0.
- Approach distance: 50.0.
- Exit distance: 50.0.

Depth Cuts
- Max rough step: 0.25.
- Finish cuts: 0.
- Finish step: 0.0.
- Для съема 1.0 мм получится 4 прохода по 0.25 мм и небольшой остаток.
	(Если указать в Linking Parameters > Depth: -1.0)
- Или Max rough step: 0.2 > Finish cuts: 1 > Finish step: 0.1 - (Будет 4 черновых и 1 финишный проходы)

Linking Parameters
- Все значения поставить Absolute.
- Clearance: 50.0.
- Retract: 10.0.
- Feed plane: 5.0.
- Top of stock: 0.0.
- Depth: -1.0.
- Включить Use clearance only at the start and end of operation.

Короткий смысл
- Face Mill используем для снятия верхнего слоя.
- Общую глубину съема задаем в Linking Parameters > Depth.
- Шаги по Z задаем в Depth Cuts.

3. Contour для боковой резки по X и Y
-------------------------------------
Перед началом
- Выбрать операцию Mastercam Contour.
- Если нужна корректная линия обработки, сначала сделать Wireframe > Offset.
- Смещение линии задает величину бокового съема.

Tool
- Tool: Flat End Mill.
- Diameter: 20 mm.
- Feed rate: 100.
- Spindle speed: 1200.
- Force tool change.

Cut Parameters
- Compensation type: Computer.
- Contour type: 2D.
- Tip comp: Tip.
- Compensation direction: Left, если инструмент идет справа от контура, а материал снимается слева.

Практика
- Для уменьшения X и Y использовать те же параметры компенсации.
- Менять только сторону обработки и величину съема.
- Перед запуском обязательно проверить траекторию в Backplot.

Linking Parameters
- Clearance: 50.0.
- Retract: 25.0.
- Feed plane: 10.0.
- Top of stock: 0.0.
- Depth: -30.0. (Зависит от длины Tool и ширины Workpiece)

Дополнительно
- Depth Cuts можно оставить нулевыми, если нужно пройти стенку сразу.
- Multi Passes включать, если нужно делить боковой съем на несколько проходов.
	На пример, если через Wireframe выбрана линия от X0 в лево -1.0, то:
	(Rough Number: 4 с Spacing 0.2 - Будет 4 черновых прохода и Finish Number: 1 с Spacing 0.2 для 1 Финишного прохода )
- Tabs выключить, если они не нужны.

4. Резка по углам с учетом радиуса
----------------------------------
Если срезать с большим диаметром Tool и оставить запас для дальнейшей обработки с меньшим Tool до конца:

[ПЕРВЫЙ ПРОХОД БОЛЬШИМ ДИАМЕТРОМ]
1. Выбрать способ резки Dynamic Mill и в Machining regions strategy выбрать: From outside > Далее выбрать углы в Machining regions > Mode: Wireframe > Chain и нажать на обрезаемую область и Enter.
2. Не закрывая Chain Options нажать на курсор мыши в Avoidance region > Mode: Solids / 3D / Loop / Face и выбрать область, которую не нужно обрезать.
Для предосмотра нажать: Preview chains.
3. В настройках Parameters > Tool: Выбрать диаметр для первой резки с остатком запаса. На пример: 10.
4. Parameters > Stock: Пока не указывать для первой резки.
5. Parameters > Cut Parameters: Stock to leave on walls и Stock to leave on floors выставить по 0.5 для остатка запаса.
(Если не нужно оставлять запас глубины Stock to leave on walls выставить: 0.0)
6. Parameters > Cut Parameters > Stepover: Выставить нужное значение для срезки боковой глубины за проход.
(По дефолту 25.0 > я выставил 15.0)
7. Parameters > Depth Cuts: Выставить половину от полного среза. На пример: 5.
(Чтобы срезал в глубину по 5.0 в несколько проходов)
8. Parameters > Entry Motion > Z clearence: 3.0 и Plungle angle: 1.8.
9. Linking Parameters: выставить все Absolute с галочкой Use clearance only at the start and end of operation.
10. Linking Parameters > Depth: Выставить максимальный срез в глубину в формате -10.

[ВТОРОЙ ПРОХОД МЕНЬШИМ ДИАМЕТРОМ]
1. Выбрать способ резки Dynamic Mill и в Machining regions strategy выбрать: From outside > Далее выбрать углы в Machining regions > Mode: Wireframe > Chain и нажать на обрезаемую область и Enter.
2. Не закрывая Chain Options нажать на курсор мыши в Avoidance region > Mode: Solids / 3D / Loop / Face и выбрать область, которую не нужно обрезать.
3. В настройках Parameters > Tool: Выбрать диаметр для финишной резки. На пример: 6 (выбрав Feed / Speed).
4. Parameters > Stock: Нажать галочку Rest material и One other operation и выбрать уже созданную операцию, которую нужно продолжить (Rest material - продолжение резки и предотвращение холостого среза по второму кругу).
5. Parameters > Cut Parameters: Выбрать нужную боковую глубину резки Stepover и на финишную резку Stock to leave on walls и Stock to leave on floors выставить по 0.0.
6. Parameters > Depth Cuts: Выключить, если глубина была срезана первым проходом.
7. Перепроверить значения: Depth Cuts / Entry Motion / Linking Parameters (выставить такой же Depth).

5. Пояснения к ключевым настройкам
----------------------------------
Machine
- Выбор модели станка, например GENERIC HAAS 3 - AXIS VMC MM.

Stock Setup
- Origin по центру удобен для симметричной обработки.
- Origin с левого нижнего угла удобен, если ноль задается от датчиков слева.

Cut Parameters
- One pass означает один проход по поверхности.
- Approach distance и Exit distance помогают сделать вход и выход инструмента мягче.

Depth Cuts
- Max rough step задает глубину одного чернового прохода.
- Finish cuts добавляет чистовые проходы.
- Finish step задает глубину чистового прохода.

Linking Parameters
- Clearance, Retract и Feed plane управляют высотами перемещений.
- Depth задает конечную глубину обработки.

Compensation
- Computer означает, что Mastercam сам считает смещение траектории.
- Tip comp удобен для 2D контура и боковой обработки.
- Left или Right выбираются по тому, с какой стороны должен идти инструмент.

6. Короткий чек-лист перед постпроцессингом
-------------------------------------------
- Размеры заготовки больше размеров детали.
- Ноль и Origin выбраны осознанно.
- Face Mill и Contour настроены отдельно.
- Компенсация контура проверена визуально.
- Trajectory просмотрена в Backplot или Verify.
