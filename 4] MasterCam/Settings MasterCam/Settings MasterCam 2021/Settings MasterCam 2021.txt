Рекомендация:
------------------------------
Чертеж детали лучше располагать с левой стороны от центра XYZ, например, X = -100, Y = 50. Это удобно, так как обычно с левой стороны установлены лазерные сенсоры для поиска нуля и контроля положения заготовки.

==============================
Шпаргалка по настройке Mastercam 2021 для генерации G-кода (Face Mill)
==============================

1. Открыть Mastercam 2021
2. Включить колонку Toolpaths через меню View
3. Выбрать станок: Machine > Mill > GENERIC HAAS 3 - AXIS VMC MM
4. Построить геометрию детали (размеры, отверстия и т.д.)
5. Открыть Properties станка (Machine Group Properties)
	 - Перейти по вкладкам: Files / Tool Settings / Stock Setup
6. Вкладка Files:
	 - Выбрать модель станка (HAAS)
	 - Поставить галочки:
		 - Output operation comments to NC
		 - Output machine name to NC
7. Вкладка Tool Settings:
	 - Spindle speed: 3000.0
	 - Feed rate: 300.0
	 - Retract rate: 300.0
	 - Plunge rate: 100.0
	 - Галочка: Adjust feed on arc move (Автоматическая корректировка подачи на дугах)
	 - Minimum arc feed: 125.0 (Минимальная подача на дуге)

	 Раздел Toolpath Configuration:
		 - Assign tool numbers sequentially (Назначать номера инструментов по порядку)
		 - Warn of duplicate tool numbers (Предупреждать о повторяющихся номерах инструментов)
		 - Use tool’s step, peck, coolant (Использовать параметры шага, прерывистой подачи, охлаждения из инструмента)

	 Раздел Advanced options:
		 - Override defaults with modal values (Переопределять значения по умолчанию модальными значениями)
		 - Clearance height (Высота зоны безопасности)
		 - Retract height (Высота отвода)
		 - Feed plane (Плоскость подачи)

	 Раздел Sequence number:
		 - Start: 1.0 (Начальный номер строки)
		 - Increment: 1.0 (Шаг увеличения номера строки)

	 Все эти параметры выставлены согласно скриншоту для обработки алюминия (ALUMINUM mm - 2024).
8. Вкладка Stock Setup:
	 - Shape: Rectangular
	 - Bounding box: Origin по центру или с левого угла (например, X = -100, Y = 0)
	 - Size: X = 103, Y = 51, Z = 25.7
		 Если Origin с левого нижнего угла (по Y = 0), то X = -100, Y = 0 — удобно для установки нуля и работы с лазерными сенсорами.
	 - (Пояснения по размерам — см. ниже)
9. Выбрать операцию Face Mill:
	 - Toolpath Group1 > Parameters > Tool:
		 - Tool: Face Mill
		 - Diameter: 63 mm
		 - Feed rate: 180
		 - RPM (Spindle speed): 1200
		 - Галочка: Force tool change
	 - Cut Parameters:
		 - Style: One pass
		 - Stock to leave on floors: 0.0 (сразу чистовой проход без остатка)
		 - Approach distance: 20.0 (Можно оставить 50) - Узнать разницу
		 - Exit distance: 20.0 (Можно оставить 50) - Узнать разницу
	 - Depth Cuts:
		 - Max rough step: 0.25 (рекомендация для Face Mill на старте)
		 - Finish cuts: 0
		 - Finish step: 0.0
		 - Подсказка (Face Mill, общий съем 1.0 мм):
			 - Linking Parameters > Depth: -1.0
			 - Если Max rough step: 0.25 и Finish cuts: 0 -> 4 прохода по 0.25
			 - Если нужен отдельный чистовой проход 0.1 мм: ставь Finish cuts: 1 и Finish step: 0.1,
			   а Max rough step: 0.3 -> 3 черновых по 0.3 мм + 1 чистовой 0.1 мм
	 - Linking Parameters:
		 - Все значения Absolute
		 - Clearance: 50.0
		 - Retract: 10.0
		 - Feed plane: 5.0
		 - Top of stock: 0.0
		 - Depth: -0.8 (пример: общий съем 0.8 мм)
		 - Галочка: Use clearance only at the start and end of operation
10. Боковые проходы для X и Y (Flat End Mill 20 mm)
		Add: Toolpaths > Contour
	 - Toolpath Group1 > Parameters > Tool:
		 - Tool: Flat End Mill
		 - Diameter: 20 mm
		 - Feed rate: 100
		 - Spindle speed: 1200
		 - Галочка: Force tool change
	 - Toolpath Group1 > Parameters > Cut Parameters:
		 - Compensation type: Computer
		 - Contour type: 2D
		 - Tip comp: Tip
		 - Compensation direction: Left (в случае, когда инструмент идет справа от контура, а снимаемый материал слева)
	 - Практика:
		 - Для операций уменьшения X и Y использовать эти же настройки компенсации,
		   а менять только нужную сторону обработки и величину съема.

==============================
Пояснения и перевод настроек
==============================

1. Files (Файлы)
----------------
- Machine — выбор модели станка. GENERIC HAAS 3 - AXIS VMC MM — стандартная 3-осевая фрезерная машина HAAS.
- Output operation comments to NC — выводить комментарии к операциям в NC-файл (пояснения к каждой операции в G-коде).
- Output machine name to NC — выводить имя станка в NC-файл (в начале G-кода будет указано, для какого станка создана программа).

2. Tool Settings (Настройки инструмента)
----------------------------------------
- Spindle speed (Обороты шпинделя) — 3000.0. Скорость вращения шпинделя в об/мин. Для алюминия обычно 2500–4000 об/мин.
- Feed rate (Подача) — 100.0. Скорость подачи инструмента по X/Y (мм/мин).
- Retract rate (Скорость подъема) — 150.0. Скорость возврата инструмента вверх (мм/мин).
- Plunge rate (Скорость погружения) — 25.0. Скорость опускания инструмента в материал (мм/мин).
- Assign tool numbers sequentially (Назначать номера инструментов по порядку) — автоматически присваивает инструментам номера 1, 2, 3...
- Warn of duplicate tool numbers (Предупреждать о повторяющихся номерах инструментов) — если два инструмента имеют одинаковый номер — появится предупреждение.
- Use tool’s step, peck, coolant (Использовать параметры шага, прерывистой подачи, охлаждения из инструмента) — использует индивидуальные параметры инструмента для шага, прерывистой подачи и охлаждения.

3. Stock Setup (Заготовка)
--------------------------
- Shape: Rectangular (Форма: прямоугольная) — выбирается, если заготовка прямоугольная.
- Bounding box: Origin по центру — точка отсчета (нулевая точка) по центру заготовки.
- Size: X = 103, Y = 51, Z = 25.7 — реальные размеры заготовки. Если чертеж детали X = 100, Y = 48, а заготовка больше (X = 103, Y = 51), то:
	- Слева и справа по X нужно убрать по (103-100)/2 = 1.5 мм, чтобы получить нужный размер детали. Если ноль по центру, то обрабатываешь по X от -50 до +50 (для детали 100 мм), а заготовка выступает за пределы детали на 1.5 мм с каждой стороны.
	- По Z аналогично: если заготовка толще, то после обработки получишь нужную высоту детали.
	- Важно: если выставляешь Origin по центру, то все размеры и смещения считаются от центра заготовки.

4. Face Mill Tool (Фреза для обработки поверхности)
---------------------------------------------------
- Toolpath Group1 > Parameters > Tool:
	- Tool diameter (Диаметр инструмента): 63.0 — диаметр торцевой фрезы. Чем больше диаметр, тем быстрее обработка плоскости.
	- Feed rate (Подача): 180.0 — скорость подачи для этой операции. Может отличаться от общей Feed rate.
	- Spindle speed / RPM (Обороты шпинделя): 1200 — обороты шпинделя для этой операции.
	- Force tool change — включить (галочка), чтобы принудительно выполнить смену инструмента в начале операции.
- FPT (Feed per tooth, подача на зуб): 0.015 — сколько миллиметров проходит каждый зуб фрезы за один оборот.

5. Cut Parameters (Параметры резки)
------------------------------------
- Style: One pass (Один проход) — вся поверхность обрабатывается за один проход.
- Stock to leave on floors (Припуск на дне): 0.0 — сразу чистовой проход без остатка, ничего не оставлять и обработать до нужного размера.
- Approach distance (Дистанция подхода): 20.0 — расстояние, с которого инструмент начинает движение к детали до начала резки. Нужно, чтобы инструмент плавно вошёл в материал.
- Exit distance (Дистанция выхода): 20.0 — расстояние, на которое инструмент выходит за пределы детали после окончания резки. Нужно для чистого выхода инструмента.

6. Depth Cuts (Глубинные проходы)
----------------------------------
- Max rough step (Максимальный шаг черновой обработки): глубина за один проход по Z.
	- Для Face Mill по алюминию безопасный старт: 0.25 мм за проход.
	- Пример: нужно снять 0.8 мм, Max rough step = 0.25 -> получится 4 прохода (0.25 + 0.25 + 0.25 + 0.05).
	- Если нужно ровно 3 прохода на 0.8 мм, ставь примерно 0.27.
- Finish cuts (Чистовые проходы): сколько дополнительных чистовых проходов добавить после черновых.
	- 0 = без отдельного чистового прохода.
	- 1 и больше = Mastercam добавит еще проход(ы) на величину Finish step.
- Finish step (Шаг чистовой обработки): глубина каждого чистового прохода.
	- Если Finish cuts = 0, то Finish step обычно ставят 0.0.
	- Если нужен легкий финальный съем, пример: Finish cuts = 1, Finish step = 0.05.
	- Вариант для Face Mill при общем съеме 1.0 мм: Finish cuts = 1, Finish step = 0.1 и Max rough step = 0.3
	  -> 3 черновых прохода по 0.3 мм и 1 чистовой проход 0.1 мм.

7. Linking Parameters (Параметры перемещений)
----------------------------------------------
- Clearance (Зона безопасности): 50.0, Absolute — высота, на которую инструмент поднимается для безопасного перемещения над деталью. Absolute — относительно общей системы координат.
- Retract (Отвод): 10.0, Absolute — высота, на которую инструмент поднимается после завершения прохода, перед перемещением к следующей точке.
- Feed plane (Плоскость подачи): 5.0, Absolute — высота, на которой инструмент начинает движение с рабочей подачей.
- Top of stock (Верх заготовки): высота верхней поверхности заготовки (обычно 0.0 в Absolute).
- Depth (Глубина): конечная глубина обработки (Absolute).
	- Общая глубина съема задается здесь, а не в Depth Cuts.
	- Формула: общий съем = Top of stock - Depth (для Absolute).
	- Пример: Top of stock = 0.0 и Depth = -0.8 -> общий съем 0.8 мм.
- Use clearance only at the start and end of operation (Использовать зону безопасности только в начале и конце операции) — инструмент поднимается на высоту Clearance только в начале и конце, а не после каждого прохода — экономит время.

8. Compensation для Flat End Mill (простое объяснение)
------------------------------------------------------
- Compensation type: Computer — Mastercam сам рассчитывает смещение траектории на радиус инструмента.
- Tip comp: Tip — расчет ведется от кончика инструмента (удобно для 2D контуров и боковых проходов).
- Contour type: 2D — обработка контура в 2D без 3D геометрии.
- Compensation direction (Left/Right) определяет, с какой стороны от траектории пойдет инструмент.
	- В твоем случае: инструмент справа, снимаемый материал слева -> Compensation direction: Left.
	- Если поменять сторону подхода инструмента, направление компенсации тоже может поменяться.
	- Перед постпроцессингом всегда проверять в Backplot/Verify, что инструмент идет с нужной стороны контура.

9. Пресет для боковой обработки Endmill Flat 20.0 mm
----------------------------------------------------
- Tool diameter: 20.0 mm.
- Depth Cuts: все по нулям.
	- Max rough step: 0.0
	- # Finish cuts: 0
	- Finish step: 0.0
- Depth Cuts можно не включать, если по глубине срезается вся плоскость/стенка сразу,
	а не делается поэтапное углубление до заданной глубины.
- Lead In/Out: без изменений.
- Break Through: выключен.
- Multi Passes: включать, если нужно делить боковой съем на несколько проходов.
	- Rough Number: количество проходов.
	- Rough Spacing: шаг между проходами.
	- Если Rough Spacing = 0.0, проходы могут повторять полный съем до финальной цепочки
	  (например, полный съем 0.85 несколько раз).
	- Проверенный вариант в твоем случае (съем 0.85 в 3 прохода):
	  Rough Number = 3, Rough Spacing = 0.2, Finish Number = 0, Finish Spacing = 0.0.
	- Если Finish passes не используются (Finish Number = 0), галочку Apply to all finish passes
	  можно снять.
	- Раздельные значения Feed rate и Spindle speed для чистовых проходов имеют смысл,
	  когда Finish passes включены.
- Tabs: выключен.
- Linking Parameters:
	- Все значения Absolute.
	- Clearance: 50.0
	- Retract: 25.0
	- Feed plane: 10.0
	- Top of stock: 0.0
	- Depth: -30.0
- Примечание:
	- Depth -30.0 указан под твою режущую кромку 40.0 mm, чтобы инструмент заходил ниже рабочей зоны и мог срезать бок стенки по всей высоте.

10. Как задать боковую глубину через Wireframe > Offset
------------------------------------------------------
- Перед всеми настройками боковой обработки сначала выбрать операцию Mastercam Contour.
- Порядок: Contour -> выбор геометрии (Chain) -> Tool -> Cut Parameters -> Linking Parameters.
- Сначала перейти в Wireframe > Offset.
- Взять верхний вид сверху и сместить линию влево на нужную величину съема.
- Эта новая смещенная линия будет показывать, сколько материала нужно снять по боку.
- Затем перейти в Parameters > Toolpath Type > Chain geometry.
	- Если старая цепочка уже выбрана, удалить ее.
	- Нажать на значок выбора цепочки (мышь).
	- Выбрать новую линию, созданную через Offset.
- Смысл этого шага:
	- Offset задает новую рабочую геометрию для бокового съема.
	- Chain geometry привязывает траекторию именно к этой новой линии.
	- Так проще контролировать, сколько снимается по X или Y до постпроцессинга.

==============================
Полезные советы
==============================
- Всегда проверяй, чтобы размеры заготовки были больше размеров детали.
- Если Origin по центру — все смещения рассчитывай от центра.
- Параметры Feed rate, Spindle speed и Plunge rate подбирай под материал и инструмент.
- Approach/Exit distance нужны для плавного входа и выхода инструмента, чтобы не было заусенцев.
- Depth Cuts — если материал твёрдый или инструмент маленький, делай больше проходов с меньшей глубиной.
- Linking Parameters — Absolute удобнее, чтобы не запутаться в координатах.
