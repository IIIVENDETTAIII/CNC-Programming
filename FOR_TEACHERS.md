## 📋 Краткая информация о проекте

**CNC Programming** - это комплексный образовательный ресурс на русском языке, созданный студентом вашей программы для помощи другим русскоязычным учащимся.

### Что включено:

- ✅ **Теория CNC** - Lessons 3-18 (полностью на русском)
- ✅ **Практические G-коды** - для SSCNC Simulator и HAAS
- ✅ **MasterCam упражнения** - 2D и 3D программирование
- ✅ **Экзаменационные материалы** - подготовка и ответы
- ✅ **Математические расчеты** - формулы и примеры

## 📚 Структура для использования в курсе

### Неделя 1-2: Введение
**Материалы:**
- `README.md` - обзор проекта
- `QUICKSTART.md` - быстрый старт для студентов
- `3] CNC Recoded Theory TXT/README.txt` - руководство

**Задание студентам:**
1. Скачать проект
2. Установить SSCNC Simulator
3. Запустить первый пример из Lesson 13

### Неделя 3-5: Основы (Lessons 3-7)
**Материалы:**
- `3] CNC Recoded Theory TXT/1] Lessons [Theory]/Lesson 3-7`
- `7] Work G-Codes [HAAS]/1] Basic G-Code/`

**Задание:**
- Изучить теорию
- Практиковаться с базовыми G-кодами
- Создать свои простые программы

### Неделя 6-8: Инструменты (Lessons 8-11)
**Материалы:**
- Lessons 8-11 (теория)
- Практические упражнения по выбору инструмента

### Неделя 9-12: Практика (Lessons 12-16)
**Материалы:**
- `1] SSCNC Simulator/` - все упражнения
- Lessons 12-16 (теория)

**Задание:**
- Пройти все упражнения в симуляторе
- Модифицировать коды
- Создать собственные программы

### Неделя 13-15: Продвинутые темы (Lessons 17-18)
**Материалы:**
- Lesson 17-18 (подпрограммы, сверление)
- `7] Work G-Codes [HAAS]/2] After Haas [Completed]/`

### Неделя 16: Подготовка к экзамену
**Материалы:**
- `2] Exam Preparation/` - все файлы
- `3] Key Points & Quick Reference/`

## 📝 Рекомендации по использованию

### ✅ Рекомендуется:

1. **Начните с обзора**
   - Покажите студентам структуру
   - Объясните, как ориентироваться
   - Дайте доступ к ресурсам

2. **Используйте последовательно**
   - Следуйте порядку Lessons 3-18
   - Не перескакивайте темы
   - Закрепляйте практикой

3. **Поощряйте вопросы**
   - Пусть создают Issues на GitHub
   - Обсуждайте в классе
   - Записывайте типичные ошибки

4. **Практика, практика, практика**
   - Каждый урок → симулятор
   - Модификация кодов
   - Свои примеры

### ❌ Не рекомендуется:

1. Пропускать теорию и сразу к практике
2. Использовать только как справочник
3. Игнорировать математические расчеты
4. Не проверять коды в симуляторе перед станком

## 🔧 Практические упражнения для занятий

### Упражнение 1: Анализ G-кода
**Файл:** `1] SSCNC Simulator/1] Lesson 13/One Flor.txt`
**Задание:** 
- Прочитать код
- Объяснить каждую строку
- Запустить в симуляторе
- Изменить размеры детали

### Упражнение 2: Модификация программы
**Файл:** `7] Work G-Codes [HAAS]/1] Basic G-Code/Face Milling.txt`
**Задание:**
- Изменить глубину резания
- Изменить подачу
- Добавить дополнительный проход
- Документировать изменения

### Упражнение 3: Создание с нуля
**Теория:** Lesson 14 (Inside Outside Profiling)
**Задание:**
- Создать программу по чертежу
- Использовать G41/G42
- Протестировать в симуляторе
- Объяснить выбор параметров
