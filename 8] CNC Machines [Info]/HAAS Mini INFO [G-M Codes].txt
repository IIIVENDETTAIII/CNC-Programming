HAAS Mini - G и M коды + как пользоваться станком
Источник: таблички на станке (фото) + учебная практика.
Дата обновления: 2026-06-05

1) Как читать табличку
Modal = код действует, пока не отменишь другим кодом из той же группы.
Non-Modal = код действует только на один блок.
Optional = зависит от комплектации станка.

5) Как пользоваться станком по шагам (кратко)
Шаг 1. Проверка: заготовка, тиски, СОЖ, воздух, чистота рабочей зоны.
Шаг 2. Включение: Power On -> Power Up/Restart -> Reset -> Zero Return All.
Шаг 3. Загрузка программы: List Prog -> USB -> выбрать файл -> Select Program.
Шаг 4. Смена инструмента вручную: MDI -> M06 T01 -> Cycle Start (дальше M06 T02 и т.д.).
Шаг 5. Длины инструментов: Offset -> Tool Offset Measure для каждого инструмента.
Шаг 6. Ноль детали: выставить G54 (X/Y/Z) по методике занятия.
Шаг 7. Пробный прогон: Memory -> Graphics + Single Block, маленькие Override.
Шаг 8. Первый реальный запуск: Cycle Start, контроль каждого движения, при риске Feed Hold.

7) Важное замечание
Конкретные функции некоторых кодов могут отличаться по опциям и версии стойки.
Для учебной работы всегда приоритет: правила преподавателя и инструкции именно вашего станка.
