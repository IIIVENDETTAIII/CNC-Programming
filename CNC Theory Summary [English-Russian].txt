CNC PROGRAMMING THEORY - KEY CONCEPTS [ENGLISH-RUSSIAN]
═══════════════════════════════════════════════════════════════════════════════

PART 1: BASIC G-CODES (G-КОДЫ)
═════════════════════════════════════════════════════════════════════════════════

1. G00 - RAPID POSITIONING / RAPIDОЕ ПОЗИЦИОНИРОВАНИЕ
────────────────────────────────────────────────────────
ENGLISH:
- G00 is used for rapid movement of the tool without cutting material
- It moves the tool from one point to another at maximum speed
- No feed rate is applied (uses machine's maximum rapid speed)
- Used for safe movements away from the workpiece

РУССКИЙ:
- G00 используется для быстрого движения инструмента без обработки материала
- Перемещает инструмент из одной точки в другую с максимальной скоростью
- Подача не применяется (используется максимальная скорость машины)
- Используется для безопасного движения от рабочей детали

Example: G00 X10 Y20 Z50
(Tool moves rapidly to coordinates X=10, Y=20, Z=50)


2. G01 - LINEAR INTERPOLATION / ЛИНЕЙНАЯ ИНТЕРПОЛЯЦИЯ
────────────────────────────────────────────────────────
ENGLISH:
- G01 is used for cutting material in a straight line
- The tool moves in a linear path while removing material
- Feed rate (F) must be specified
- Maintains constant cutting speed and direction

РУССКИЙ:
- G01 используется для обработки материала по прямой линии
- Инструмент движется по линейной траектории, удаляя материал
- Необходимо указать подачу (F)
- Поддерживает постоянную скорость резания и направление

Example: G01 X50 Y30 Z-10 F150
(Tool cuts material moving to X=50, Y=30, Z=-10 at feedrate 150 mm/min)


3. G02 - CLOCKWISE CIRCULAR INTERPOLATION / КРУГОВАЯ ИНТЕРПОЛЯЦИЯ ПО ЧАСОВОЙ СТРЕЛКЕ
───────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G02 creates a circular arc in the clockwise direction
- Used for curved cuts and contours
- Requires center point (I, J, K) or radius (R)
- Feed rate must be specified

РУССКИЙ:
- G02 создает круговую дугу в направлении по часовой стрелке
- Используется для криволинейных обработок и контуров
- Требует центральную точку (I, J, K) или радиус (R)
- Необходимо указать подачу

Example: G02 X100 Y50 I50 J25 F100
(Clockwise circular cut with center at offset I=50, J=25)


4. G03 - COUNTERCLOCKWISE CIRCULAR INTERPOLATION / КРУГОВАЯ ИНТЕРПОЛЯЦИЯ ПРОТИВ ЧАСОВОЙ СТРЕЛКИ
──────────────────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G03 creates a circular arc in the counterclockwise direction
- Used for curved cuts in opposite direction to G02
- Requires center point (I, J, K) or radius (R)
- Feed rate must be specified

РУССКИЙ:
- G03 создает круговую дугу в направлении против часовой стрелки
- Используется для криволинейных обработок в противоположном направлении G02
- Требует центральную точку (I, J, K) или радиус (R)
- Необходимо указать подачу

Example: G03 X100 Y50 I50 J25 F100


5. G17 - XY PLANE SELECTION / ВЫБОР ПЛОСКОСТИ XY
────────────────────────────────────────────────
ENGLISH:
- G17 selects the XY plane as the working plane
- Used in milling operations (most common)
- Perpendicular plane is Z axis
- Safety code that must be specified at program start

РУССКИЙ:
- G17 выбирает плоскость XY как рабочую плоскость
- Используется при операциях фрезерования (наиболее распространено)
- Перпендикулярная плоскость - ось Z
- Код безопасности, который должен быть указан в начале программы

Example: G17 (All circular motions will use XY plane)


6. G18 - XZ PLANE SELECTION / ВЫБОР ПЛОСКОСТИ XZ
────────────────────────────────────────────────
ENGLISH:
- G18 selects the XZ plane as the working plane
- Used in turning operations
- Perpendicular plane is Y axis

РУССКИЙ:
- G18 выбирает плоскость XZ как рабочую плоскость
- Используется при операциях токарной обработки
- Перпендикулярная плоскость - ось Y

Example: G18 (Used for turning lathe operations)


7. G19 - YZ PLANE SELECTION / ВЫБОР ПЛОСКОСТИ YZ
────────────────────────────────────────────────
ENGLISH:
- G19 selects the YZ plane as the working plane
- Less commonly used
- Perpendicular plane is X axis

РУССКИЙ:
- G19 выбирает плоскость YZ как рабочую плоскость
- Используется реже
- Перпендикулярная плоскость - ось X


8. G20 - IMPERIAL UNITS (INCHES) / ИМПЕРСКИЕ ЕДИНИЦЫ (ДЮЙМЫ)
──────────────────────────────────────────────────────────────
ENGLISH:
- G20 sets the machine to work with imperial units (inches)
- All coordinates will be interpreted as inches
- One inch = 25.4 millimeters

РУССКИЙ:
- G20 устанавливает машину на работу в имперских единицах (дюймы)
- Все координаты будут интерпретированы как дюймы
- Один дюйм = 25,4 миллиметра

Example: G20 (All following dimensions in inches)


9. G21 - METRIC UNITS (MILLIMETERS) / МЕТРИЧЕСКИЕ ЕДИНИЦЫ (МИЛЛИМЕТРЫ)
──────────────────────────────────────────────────────────────────────
ENGLISH:
- G21 sets the machine to work with metric units (millimeters)
- All coordinates will be interpreted as millimeters
- Most common in modern CNC programming
- Must be specified at the beginning of the program

РУССКИЙ:
- G21 устанавливает машину на работу в метрических единицах (миллиметры)
- Все координаты будут интерпретированы как миллиметры
- Наиболее распространено в современном программировании ЧПУ
- Должно быть указано в начале программы

Example: G21 (All following dimensions in millimeters)


10. G28 - RETURN TO HOME POSITION / ВОЗВРАТ В ИСХОДНОЕ ПОЛОЖЕНИЕ
──────────────────────────────────────────────────────────────────
ENGLISH:
- G28 returns the tool to the machine's home position (machine zero)
- Often prefixed with G91 for incremental movement to home
- Used for safety at the end of program
- Brings tool away from the workpiece

РУССКИЙ:
- G28 возвращает инструмент в исходное положение машины (нулевая позиция машины)
- Часто предваряется G91 для инкрементального движения к дому
- Используется для безопасности в конце программы
- Отводит инструмент от рабочей детали

Example: G91 G28
(Return to home position using incremental mode)


11. G40 - CANCEL CUTTER RADIUS COMPENSATION / ОТМЕНА КОМПЕНСАЦИИ РАДИУСА РЕЗЦА
─────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G40 cancels the cutter radius compensation (G41 or G42)
- Must be used to deactivate radius offset before moving away
- Essential for program safety
- Prevents over-cutting or under-cutting

РУССКИЙ:
- G40 отменяет компенсацию радиуса резца (G41 или G42)
- Должно использоваться для деактивации смещения радиуса перед движением
- Критично для безопасности программы
- Предотвращает переобработку или недоработку

Example: G40 X100 Y100
(Cancel radius compensation and move to safe position)


12. G41 - CUTTER RADIUS COMPENSATION LEFT / КОМПЕНСАЦИЯ РАДИУСА РЕЗЦА СЛЕВА
──────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G41 applies cutter radius compensation to the left of the tool path
- Used when cutting on the left side of the programmed path
- Requires tool diameter offset (D)
- Allows use of various tool diameters with same program

РУССКИЙ:
- G41 применяет компенсацию радиуса резца слева от пути инструмента
- Используется при резании с левой стороны запрограммированной траектории
- Требует смещение диаметра инструмента (D)
- Позволяет использовать инструменты разных диаметров с одной программой

Example: G41 G01 X50 Y30 D1 F100
(Cut with radius compensation left, using offset D1)


13. G42 - CUTTER RADIUS COMPENSATION RIGHT / КОМПЕНСАЦИЯ РАДИУСА РЕЗЦА СПРАВА
─────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G42 applies cutter radius compensation to the right of the tool path
- Used when cutting on the right side of the programmed path
- Requires tool diameter offset (D)
- Most commonly used for outside contours

РУССКИЙ:
- G42 применяет компенсацию радиуса резца справа от пути инструмента
- Используется при резании с правой стороны запрограммированной траектории
- Требует смещение диаметра инструмента (D)
- Наиболее часто используется для внешних контуров

Example: G42 G01 X50 Y30 D1 F100
(Cut with radius compensation right, using offset D1)


14. G43 - TOOL LENGTH COMPENSATION POSITIVE / КОМПЕНСАЦИЯ ДЛИНЫ ИНСТРУМЕНТА (ПОЛОЖИТЕЛЬНАЯ)
──────────────────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G43 applies tool length offset
- Compensates for different tool heights
- Requires tool offset number (H)
- Must be used with Z movement
- Essential for safe tool positioning

РУССКИЙ:
- G43 применяет компенсацию длины инструмента
- Компенсирует различные высоты инструментов
- Требует номер смещения инструмента (H)
- Должно использоваться с движением Z
- Критично для безопасного позиционирования инструмента

Example: G43 H1 Z50
(Apply tool offset H1 and move to Z=50)


15. G49 - CANCEL TOOL LENGTH COMPENSATION / ОТМЕНА КОМПЕНСАЦИИ ДЛИНЫ ИНСТРУМЕНТА
──────────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- G49 cancels tool length offset compensation
- Used when moving away from cutting area
- Deactivates the height offset
- Necessary for tool change sequences

РУССКИЙ:
- G49 отменяет компенсацию смещения длины инструмента
- Используется при движении в сторону от области резания
- Деактивирует смещение высоты
- Необходимо для последовательности смены инструмента

Example: G49 (Deactivate tool length offset)


16. G80 - CANCEL CANNED CYCLE / ОТМЕНА ПОДПРОГРАММЫ ЦИКЛА
──────────────────────────────────────────────────────────
ENGLISH:
- G80 cancels active canned cycles (G81, G82, G83, etc.)
- Used before ending drilling or tapping operations
- Resets machine to standard mode
- Safety measure to prevent unwanted repetitive cycles

РУССКИЙ:
- G80 отменяет активные подпрограммы циклов (G81, G82, G83 и т.д.)
- Используется перед завершением операций сверления или нарезания резьбы
- Сбрасывает машину в стандартный режим
- Мера безопасности для предотвращения нежелаемых повторяющихся циклов

Example: G80 (Cancel all active canned cycles)


17. G90 - ABSOLUTE POSITIONING / АБСОЛЮТНОЕ ПОЗИЦИОНИРОВАНИЕ
─────────────────────────────────────────────────────────────
ENGLISH:
- G90 sets the machine to absolute positioning mode
- All coordinates are measured from the machine zero point
- X10 means move to absolute position X=10
- Most common mode in modern CNC

РУССКИЙ:
- G90 устанавливает машину в режим абсолютного позиционирования
- Все координаты измеряются от нулевой точки машины
- X10 означает движение в абсолютную позицию X=10
- Наиболее частый режим в современном ЧПУ

Example: G90 (Absolute positioning mode active)


18. G91 - INCREMENTAL POSITIONING / ИНКРЕМЕНТНОЕ ПОЗИЦИОНИРОВАНИЕ
───────────────────────────────────────────────────────────────────
ENGLISH:
- G91 sets the machine to incremental positioning mode
- Coordinates are relative to the current position
- X10 means move 10 units from current position
- Used with G28 for safe home return (G91 G28)

РУССКИЙ:
- G91 устанавливает машину в режим инкрементного позиционирования
- Координаты относительны к текущей позиции
- X10 означает движение на 10 единиц от текущей позиции
- Используется с G28 для безопасного возврата на дом (G91 G28)

Example: G91 G28 (Return home incrementally)

PART 2: BASIC M-CODES (М-КОДЫ)
═════════════════════════════════════════════════════════════════════════════════

1. M00 - PROGRAM STOP / ОСТАНОВКА ПРОГРАММЫ
──────────────────────────────────────────────
ENGLISH:
- M00 causes the program to stop temporarily
- Machine stops all functions (spindle, coolant, feed)
- Operator must manually restart the program
- Used when operator intervention is required

РУССКИЙ:
- M00 вызывает временную остановку программы
- Машина останавливает все функции (шпиндель, охладитель, подача)
- Оператор должен вручную перезапустить программу
- Используется, когда требуется вмешательство оператора

Example: M00


2. M01 - OPTIONAL PROGRAM STOP / ФАКУЛЬТАТИВНАЯ ОСТАНОВКА ПРОГРАММЫ
────────────────────────────────────────────────────────────────────
ENGLISH:
- M01 is a conditional stop that only activates if "Optional Stop" is enabled
- Allows operator to pause program if needed
- Used for checking intermediate results
- No effect if optional stop is disabled

РУССКИЙ:
- M01 - условная остановка, которая активируется только если включена "факультативная остановка"
- Позволяет оператору паузировать программу при необходимости
- Используется для проверки промежуточных результатов
- Нет эффекта, если факультативная остановка отключена

Example: M01


3. M02 - PROGRAM END / КОНЕЦ ПРОГРАММЫ
────────────────────────────────────────
ENGLISH:
- M02 ends the program and returns to the beginning
- Does NOT automatically eject or reset
- Spindle and coolant remain on
- Used less frequently than M30

РУССКИЙ:
- M02 завершает программу и возвращает в начало
- НЕ автоматически эжектирует или сбрасывает
- Шпиндель и охладитель остаются включены
- Используется реже, чем M30

Example: M02


4. M03 - SPINDLE START (CLOCKWISE) / ЗАПУСК ШПИНДЕЛЯ (ПО ЧАСОВОЙ СТРЕЛКЕ)
────────────────────────────────────────────────────────────────────────────
ENGLISH:
- M03 starts the spindle rotating clockwise
- Speed must be specified with S code (S1000 = 1000 RPM)
- Used before cutting operations
- Essential for all milling operations

РУССКИЙ:
- M03 запускает шпиндель с вращением по часовой стрелке
- Скорость должна быть указана с кодом S (S1000 = 1000 об/мин)
- Используется перед операциями резания
- Критично для всех операций фрезерования

Example: M03 S1500
(Start spindle at 1500 RPM clockwise)


5. M04 - SPINDLE START (COUNTERCLOCKWISE) / ЗАПУСК ШПИНДЕЛЯ (ПРОТИВ ЧАСОВОЙ СТРЕЛКИ)
───────────────────────────────────────────────────────────────────────────────────
ENGLISH:
- M04 starts the spindle rotating counterclockwise
- Speed must be specified with S code
- Used for special cutting operations requiring opposite rotation
- Less common than M03

РУССКИЙ:
- M04 запускает шпиндель с вращением против часовой стрелки
- Скорость должна быть указана с кодом S
- Используется для специальных операций резания, требующих противоположного вращения
- Менее распространено, чем M03

Example: M04 S1000
(Start spindle at 1000 RPM counterclockwise)


6. M05 - SPINDLE STOP / ОСТАНОВКА ШПИНДЕЛЯ
────────────────────────────────────────────
ENGLISH:
- M05 stops the spindle rotation
- Must be used before tool change
- Used at end of cutting operations
- Essential for safety before retracting tool

РУССКИЙ:
- M05 останавливает вращение шпинделя
- Должно использоваться перед заменой инструмента
- Используется в конце операций резания
- Критично для безопасности перед втягиванием инструмента

Example: M05


7. M06 - AUTOMATIC TOOL CHANGE / АВТОМАТИЧЕСКАЯ СМЕНА ИНСТРУМЕНТА
───────────────────────────────────────────────────────────────────
ENGLISH:
- M06 activates the automatic tool changer
- Must be followed by tool number (T01, T02, etc.)
- Tool is picked from magazine and inserted into spindle
- Spindle must be stopped before tool change (M05 first)

РУССКИЙ:
- M06 активирует автоматический инструментальный магазин
- Должно быть указано номер инструмента (T01, T02 и т.д.)
- Инструмент берется из магазина и вставляется в шпиндель
- Шпиндель должен быть остановлен перед заменой инструмента (сначала M05)

Example: M06 T01
(Tool change - insert tool number 1)


8. M08 - COOLANT ON / ВКЛЮЧИТЬ ОХЛАДИТЕЛЬ
─────────────────────────────────────────────
ENGLISH:
- M08 turns on the coolant pump
- Delivers coolant to the cutting area
- Reduces temperature and improves surface finish
- Must be turned on before cutting material

РУССКИЙ:
- M08 включает насос охладителя
- Подает охладитель в область обработки
- Снижает температуру и улучшает качество поверхности
- Должно быть включено перед обработкой материала

Example: M08


9. M09 - COOLANT OFF / ВЫКЛЮЧИТЬ ОХЛАДИТЕЛЬ
──────────────────────────────────────────────
ENGLISH:
- M09 turns off the coolant pump
- Used when coolant is no longer needed
- Stops coolant delivery
- Important before tool retraction

РУССКИЙ:
- M09 выключает насос охладителя
- Используется, когда охладитель больше не требуется
- Останавливает подачу охладителя
- Важно перед втягиванием инструмента

Example: M09


10. M30 - PROGRAM END AND REWIND / КОНЕЦ ПРОГРАММЫ И ПЕРЕМОТКА
───────────────────────────────────────────────────────────────
ENGLISH:
- M30 ends the program completely
- Resets all functions (spindle off, coolant off)
- Returns to program start for automatic repeat
- Most common program ending code
- Preferred over M02 for mass production

РУССКИЙ:
- M30 полностью завершает программу
- Сбрасывает все функции (шпиндель выключен, охладитель выключен)
- Возвращает в начало программы для автоматического повтора
- Наиболее часто используемый код завершения программы
- Предпочтителен M02 для массового производства

Example: M30

PART 3: FUNDAMENTAL CONCEPTS (ОСНОВНЫЕ КОНЦЕПЦИИ)
═════════════════════════════════════════════════════════════════════════════════

1. WORK COORDINATE SYSTEM (WCS) / РАБОЧАЯ СИСТЕМА КООРДИНАТ
─────────────────────────────────────────────────────────────
ENGLISH:
- G54, G55, G56, G57, G58, G59 - Different work coordinate systems
- Each number represents a different vice or fixture position
- When program calls G54 X0 Y0, it goes to that specific offset point
- Essential for multi-vice setups or different workpieces
- Offsets are stored in machine's offset table

РУССКИЙ:
- G54, G55, G56, G57, G58, G59 - Различные рабочие системы координат
- Каждый номер представляет различное положение тисков или приспособления
- Когда программа вызывает G54 X0 Y0, она переходит к этой конкретной точке смещения
- Критично для установок с несколькими тисками или разными рабочими деталями
- Смещения хранятся в таблице смещений машины

Example Scenario:
G54 X0 Y0 (Go to vice #1 origin)
G55 X0 Y0 (Go to vice #2 origin)
G56 X0 Y0 (Go to vice #3 origin)


2. TOOL OFFSET / СМЕЩЕНИЕ ИНСТРУМЕНТА
────────────────────────────────────────
ENGLISH:
- Each tool has a unique offset number (H1, H2, H3, etc.)
- Offset stores tool length and diameter information
- Tool length offset: Compensates for different tool heights
- Diameter offset: Used with cutter radius compensation (G41/G42)
- Must match the tool loaded in the spindle
- Operator responsibility to load correct offset

РУССКИЙ:
- Каждый инструмент имеет уникальный номер смещения (H1, H2, H3 и т.д.)
- Смещение хранит информацию о длине и диаметре инструмента
- Смещение длины инструмента: компенсирует различные высоты инструментов
- Смещение диаметра: используется с компенсацией радиуса резца (G41/G42)
- Должно совпадать с инструментом, загруженным в шпиндель
- Ответственность оператора - загрузить правильное смещение

Example:
H1 = Tool 1 length and diameter
H2 = Tool 2 length and diameter
When using G43 H1, machine applies offset H1


3. CUTTING SPEED (VC) / СКОРОСТЬ РЕЗАНИЯ
───────────────────────────────────────────
ENGLISH:
- Vc = Cutting speed (manufacturer parameter, in meters/minute)
- Different materials require different cutting speeds:
  * Aluminum: 60-450 m/min (high speed)
  * Steel: 20-100 m/min (lower speed - hard material)
  * Plastic: 100-200 m/min (high speed)
  * Wood: 50+ m/min (high speed)
- Cutting speed increases with softer materials
- Cutting speed decreases with harder materials
- Affected by tool coating (carbide, high-speed steel, etc.)

РУССКИЙ:
- Vc = Скорость резания (параметр производителя, в метрах/минуту)
- Различные материалы требуют разных скоростей резания:
  * Алюминий: 60-450 м/мин (высокая скорость)
  * Сталь: 20-100 м/мин (более низкая скорость - твердый материал)
  * Пластик: 100-200 м/мин (высокая скорость)
  * Дерево: 50+ м/мин (высокая скорость)
- Скорость резания увеличивается при работе с более мягкими материалами
- Скорость резания уменьшается при работе с более твердыми материалами
- Зависит от покрытия инструмента (карбид, быстрорежущая сталь и т.д.)


4. SPINDLE SPEED (RPM) / СКОРОСТЬ ШПИНДЕЛЯ
──────────────────────────────────────────────
ENGLISH:
Formula: N = (Vc × 1000) / (π × D)
Where:
- N = Spindle speed (RPM - Revolutions Per Minute)
- Vc = Cutting speed (m/min)
- D = Tool diameter (mm)
- π (pi) = 3.14159

Key points:
- Smaller diameter tools = Higher RPM
- Larger diameter tools = Lower RPM
- Inversely proportional: If diameter increases, speed decreases

РУССКИЙ:
Формула: N = (Vc × 1000) / (π × D)
Где:
- N = Скорость шпинделя (об/мин)
- Vc = Скорость резания (м/мин)
- D = Диаметр инструмента (мм)
- π (пи) = 3,14159

Ключевые моменты:
- Инструменты меньшего диаметра = Более высокие об/мин
- Инструменты большего диаметра = Более низкие об/мин
- Обратно пропорциональна: Если диаметр увеличивается, скорость уменьшается

Example Calculation:
Tool diameter: 10mm
Cutting speed (Vc): 80 m/min
N = (80 × 1000) / (3.14 × 10) = 2546 RPM
Practical speed: Use 75% = 2546 × 0.75 ≈ 1900 RPM


5. FEED RATE (F) / ПОДАЧА (СКОРОСТЬ ПОДАЧИ)
────────────────────────────────────────────────
ENGLISH:
Formula: F = N × Z × FPT
Where:
- F = Feed rate (mm/min)
- N = Spindle speed (RPM)
- Z = Number of flutes (teeth) on tool
- FPT = Feed per tooth (mm) - manufacturer parameter

Key points:
- Feed rate depends on three factors: Speed, flutes, and feed per tooth
- More flutes = Higher feed rate possible
- Larger feed per tooth = Higher feed rate
- Too high feed = Tool breaks, too low = inefficiency

РУССКИЙ:
Формула: F = N × Z × FPT
Где:
- F = Подача (мм/мин)
- N = Скорость шпинделя (об/мин)
- Z = Количество зубьев (флейт) на инструменте
- FPT = Подача на зуб (мм) - параметр производителя

Ключевые моменты:
- Подача зависит от трех факторов: скорость, количество флейт, подача на зуб
- Больше флейт = Возможна более высокая подача
- Большая подача на зуб = Более высокая подача
- Слишком высокая подача = Инструмент ломается, слишком низкая = неэффективность

Example Calculation:
Spindle speed: 1900 RPM
Number of flutes: 3
Feed per tooth: 0.05 mm
F = 1900 × 3 × 0.05 = 285 mm/min
Practical feed: Use 75% = 285 × 0.75 ≈ 215 mm/min


6. STEP DOWN (AXIAL DEPTH OF CUT) / ГЛУБИНА ВРЕЗАНИЯ (ОСЕВАЯ ГЛУБИНА)
───────────────────────────────────────────────────────────────────────
ENGLISH:
- Step down is the Z-axis depth you cut in each pass
- Related to plunge speed and tool strength
- Smaller tools = Smaller step down values
- Larger tools = Can handle larger step down
- Maximum recommended: Don't cut full depth in one pass for most tools
- For 10mm deep cut: Could do Z-2, Z-4, Z-6, Z-8, Z-10 (multiple passes)

РУССКИЙ:
- Глубина врезания - это глубина по оси Z, которую вы режете в каждом проходе
- Связана со скоростью погружения и прочностью инструмента
- Меньшие инструменты = Меньшие значения глубины врезания
- Большие инструменты = Могут справиться с большей глубиной врезания
- Максимум рекомендуемого: Не режьте полную глубину за один проход для большинства инструментов
- Для 10мм глубины: Можно делать Z-2, Z-4, Z-6, Z-8, Z-10 (несколько проходов)


7. STEP OVER (RADIAL DEPTH OF CUT) / ШАГ ПОДАЧИ В ПЛАНЕ (РАДИАЛЬНАЯ ГЛУБИНА)
─────────────────────────────────────────────────────────────────────────────
ENGLISH:
- Step over is the amount of material removed in X/Y direction per pass
- Related to surface finish quality
- Smaller step over = Better surface finish but longer cycle time
- Larger step over = Faster cutting but rougher finish
- Usually: 10-50% of tool diameter for roughing
- Finishing passes: Very small step over (1-5% of diameter)

РУССКИЙ:
- Шаг подачи в плане - это количество материала, удаляемого в направлении X/Y за один проход
- Связана с качеством чистоты поверхности
- Меньший шаг подачи = Лучшей качество поверхности, но более длительное время цикла
- Больший шаг подачи = Более быстрое резание, но грубее обработка
- Обычно: 10-50% диаметра инструмента для черновой обработки
- Финишные проходы: Очень малый шаг подачи (1-5% диаметра)


8. CUTTER RADIUS COMPENSATION (G41 / G42) / КОМПЕНСАЦИЯ РАДИУСА РЕЗЦА
──────────────────────────────────────────────────────────────────────
ENGLISH:
- Allows using different diameter tools with the same program
- G41: Compensation on LEFT side of tool path
- G42: Compensation on RIGHT side of tool path (most common for outside cuts)
- Machine automatically adjusts tool position based on diameter offset
- Without compensation: Would need to recalculate program for each tool diameter
- CRITICAL: Must match actual tool diameter in offset table

РУССКИЙ:
- Позволяет использовать инструменты разных диаметров с одной программой
- G41: Компенсация на ЛЕВОЙ стороне пути инструмента
- G42: Компенсация на ПРАВОЙ стороне пути инструмента (наиболее частая для внешних контуров)
- Машина автоматически регулирует положение инструмента на основе смещения диаметра
- Без компенсации: Нужно пересчитывать программу для каждого диаметра инструмента
- КРИТИЧНО: Должно совпадать с фактическим диаметром инструмента в таблице смещений

Example:
G42 D1 means use radius compensation right with diameter offset D1
If D1 = 10mm: Tool offset 10mm from programmed path
If you change to 12mm tool: Update D1 to 12mm, program stays same

PART 5: PROGRAM CONVENTIONS / СОГЛАШЕНИЯ ПРОГРАММИРОВАНИЯ
═════════════════════════════════════════════════════════════════════════════════

1. PROGRAM HEADER / ЗАГОЛОВОК ПРОГРАММЫ
─────────────────────────────────────────
ENGLISH:
- Every program starts with % (percentage sign)
- Program number: O0001-O99999
- Comment line with material, tools, date information
- Safety codes (G17, G21, G40, G90) always first
- Header sets up machine for proper operation

РУССКИЙ:
- Каждая программа начинается с % (знак процента)
- Номер программы: O0001-O99999
- Комментарий с информацией о материале, инструментах, дате
- Коды безопасности (G17, G21, G40, G90) всегда первыми
- Заголовок настраивает машину для правильной работы


2. PROGRAM BODY / ОСНОВНОЕ СОДЕРЖАНИЕ ПРОГРАММЫ
─────────────────────────────────────────────────
ENGLISH:
- Contains all cutting movements
- G00 for rapid positioning (safety)
- G01 for linear cutting
- G02/G03 for circular cutting
- M codes for machine functions
- Careful sequencing of operations


РУССКИЙ:
- Содержит все движения резания
- G00 для быстрого позиционирования (безопасность)
- G01 для линейного резания
- G02/G03 для кругового резания
- М-коды для функций машины
- Осторожная последовательность операций


3. PROGRAM ENDING / ОКОНЧАНИЕ ПРОГРАММЫ
─────────────────────────────────────────
ENGLISH:
- Always end with M30 (end and rewind)
- Finish with % (percentage sign)
- Never leave spindle running
- Always retract tool to safe height
- Always return to home position


РУССКИЙ:
- Всегда завершайте M30 (конец и перемотка)
- Завершите с % (знак процента)
- Никогда не оставляйте шпиндель работающим
- Всегда втягивайте инструмент на безопасную высоту
- Всегда возвращайтесь в исходное положение

IMPORTANT NOTES / ВАЖНЫЕ ЗАМЕЧАНИЯ
═════════════════════════════════════════════════════════════════════════════════

SAFETY FIRST / БЕЗОПАСНОСТЬ В ПЕРВУЮ ОЧЕРЕДЬ:
- Always use G00 for positioning away from work
- Always apply tool offsets with G43
- Always cancel compensation with G40
- Always check machine capacity before program
- Use 75% of calculated speed for safety margin

OPTIMIZATION / ОПТИМИЗАЦИЯ:
- Calculate speeds and feeds before starting
- Use trial and error method to find optimal values
- Adjust based on actual machine performance
- Higher speed and feed = Better surface finish but more load on tool
- Balance between speed and tool life

COMMON MISTAKES / ОБЫЧНЫЕ ОШИБКИ:
- Wrong tool diameter in offset table = Program fails
- Not using G43 for height compensation = Crash risk
- Using wrong plane selection (G17/G18/G19) = Incorrect movements
- Not canceling compensation (G40) = Extra material removed
- Not returning to home after program = Safety hazard
