README — Как пользоваться теорией CNC

Структура папки:

1] Lessons [Theory]
    Основная теория по каждому уроку (Lesson 3 — Lesson 18B).
    Также включает CNC EXAM REVIEW GUIDE и Manual Handling.
    Открывай нужный урок по номеру или теме.

2] Exam Preparation
    Все файлы для подготовки к экзамену.
    Ответы на вопросы, pre-exam материалы, записи с урока 31.03.2026.
    Начинай отсюда перед экзаменом.

3] Key Points & Quick Reference
    Важные моменты по CNC — краткий справочник.
    Практические советы и типовые ошибки.
    Идеально для быстрого повторения.

4] Business & Engineering Theory
    Теория по бизнесу и коммуникациям в инженерии (на английском и русском).

5] NEW [Новые записи]
    Сюда добавляются новые записи с микрофона.
    После обработки — материалы интегрируются в соответствующие уроки и разделы.

Файлы в корне:
    README.txt — этот файл.
    CNC Theory Contents.txt — полное оглавление со списком всех тем.

Совет: текст оформлен без лишних символов — удобно для прослушивания (TTS).
