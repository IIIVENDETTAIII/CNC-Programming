README — Как пользоваться теорией CNC

1. Для быстрого повторения и подготовки к экзамену начните с файла "Важные моменты по CNC.txt".
2. Для углубленного изучения используйте файлы из папки Lessons — каждый файл соответствует отдельной теме или уроку.
3. Новые материалы из папки NEW уже интегрированы в основные разделы и важные моменты.
4. Для поиска конкретной темы используйте файл "CNC Theory Contents.txt" (оглавление) или функцию поиска по папке.
5. Все материалы структурированы по принципу: теория → практика → экзамен → новые материалы.

Текст оформлен для легкости восприятия и прослушивания (TTS). Если нужно добавить новые темы — просто создайте новый файл и добавьте его в оглавление.

Удачи в учебе и на экзамене!
