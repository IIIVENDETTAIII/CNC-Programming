Да, STL — это как раз основной формат для 3D-печати. Но есть важный момент:

**STL предназначен для печати, а не для удобного редактирования.** Его можно менять, но это сложнее, чем работать с исходной CAD-моделью (Fusion 360, SolidWorks и т.д.).

По твоему скриншоту у тебя уже есть почти всё необходимое:

* ✅ Autodesk Fusion 360 — один из лучших вариантов.
* ✅ SolidWorks 2018 — профессиональный вариант.
* ✅ Blender 4.5 — подходит для редактирования STL-сеток.
* ✅ Cura — для подготовки модели к печати на Ultimaker.
* ❌ AutoCAD для таких задач не лучший выбор.

### Самый простой путь для новичка

**STL → Fusion 360 → Cura → Ultimaker**

---

# Вариант 1. Fusion 360 (рекомендую)

Если нужно:

* увеличить размеры;
* сделать отверстия;
* добавить крепления;
* убрать лишние части;

то Fusion 360 отлично подходит.

### Шаг 1

Скачиваешь STL.

### Шаг 2

Открываешь Fusion 360.

### Шаг 3

File → Open → STL.

### Шаг 4

Преобразовываешь сетку:

Mesh → Convert Mesh.

После этого STL станет твердотельной моделью.

### Шаг 5

Редактируешь:

* Extrude;
* Cut;
* Hole;
* Fillet;
* Chamfer.

Как обычную CAD-модель.

### Шаг 6

Экспортируешь обратно:

File → Export → STL.

---

# Вариант 2. Blender

Подходит если нужно:

* двигать части модели;
* изменять форму;
* сглаживать;
* лепить новую форму поверх старой.

Открываешь STL:

File → Import → STL.

После изменений:

File → Export → STL.

---

# Вариант 3. Самый простой — Meshmixer

Многие используют именно его для STL.

Позволяет:

* резать модель;
* соединять модели;
* делать отверстия;
* менять размеры.

Программа бесплатная.

Если STL сложный, иногда Meshmixer даже удобнее Fusion.

---

# После редактирования

Открываешь Cura.

### Для Ultimaker:

1. Добавить принтер Ultimaker.
2. Загружаешь STL.
3. Настраиваешь:

   * Layer Height.
   * Infill.
   * Supports.
4. Нажимаешь Slice.
5. Получаешь G-code.

Этот G-code уже отправляется на принтер.

---

# Конкретно для твоего держателя GoPro

Если ты скачаешь только STL с Printables:

```
GoPro-chest-magnet-holder-Kasper.stl
```

то ты сможешь:

* изменить толщину магнита;
* усилить крепление;
* увеличить размеры под свою грудь;
* добавить место под другой магнит;
* изменить угол камеры.

Но редактирование будет сложнее, чем если автор выложил бы исходник Fusion 360 или STEP.

---

# Что бы я использовал на твоём месте

1. Скачать STL.
2. Открыть в Fusion 360.
3. Конвертировать Mesh → Solid.
4. Внести изменения.
5. Сохранить новый STL.
6. Открыть в Cura.
7. Сгенерировать G-code для Ultimaker.

Если скинешь ссылку на этот держатель с Printables или сам STL-файл, я могу подсказать конкретно:

* в какой программе его лучше править;
* насколько он вообще редактируемый;
* как усилить конструкцию для футбола, чтобы GoPro не отлетела при столкновении.
