## Полный разбор G-кода (строка за строкой)

```cnc
%
```
**Символ начала программы** (не является командой для станка, просто обозначает начало файла).

```cnc
00001 ;
```
**Номер программы** (обычно 4-5 цифр). Используется для идентификации программы в памяти станка.

```cnc
(A1-100x80x20mmdiameter16-Mano) ;
```
**Комментарий.** Не влияет на выполнение. Здесь указано: "A1, заготовка 100x80x20мм, диаметр фрезы 16мм, ручное программирование (Mano)".

### Блок подготовки (безопасность и настройки)

```cnc
G21 G17 G90 G40 G49 ;
```
Это **строка безопасности**. Здесь сразу устанавливаются все важные режимы:
- **G21** – работа в **метрической системе** (миллиметры).
- **G17** – выбор плоскости **XY** (основная плоскость для фрезеровки).
- **G90** – **абсолютное позиционирование**. Все координаты (X, Y, Z) отсчитываются от нуля детали (G54).
- **G40** – **отмена компенсации на радиус инструмента** (на всякий случай, чтобы предыдущая программа ее не оставила).
- **G49** – **отмена коррекции на длину инструмента** (сброс предыдущих значений).

```cnc
G91 G28 Z0 ;
```
**Возврат в "домашнюю" позицию по оси Z.**  
`G91` – временно включаем **относительный режим**. `G28 Z0` – отправить ось Z в "ноль станка" (самая верхняя безопасная точка) через промежуточную точку. Это гарантирует, что инструмент не врежется в заготовку при смене.

```cnc
M06 T02 ;
```
**Смена инструмента.** Станок останавливается, ждет, пока оператор (или автоматика) установит **инструмент номер 2 (T02)** – нашу фрезу 16мм.

```cnc
G90 G00 G54 X0 Y0 ;
```
**Активация системы координат и быстрый подход.**  
`G90` – снова включаем **абсолютный режим** (после G91).  
`G54` – выбираем **рабочую систему координат №1** (ноль детали, который мы выставили заранее).  
`G00 X0 Y0` – **быстрое перемещение** (на максимальной скорости) в центр заготовки (X=0, Y=0).

```cnc
G00 G43 Z50 H01 ;
```
**Активация коррекции на длину инструмента и подъем.**  
`G43` – включить **положительную коррекцию на длину инструмента**. Станок берет значение длины из регистра **H01** и добавляет его к текущей команде по Z. Это нужно, чтобы станок "понимал", где находится кончик фрезы относительно нуля детали.  [Не понял про положительную коррекцию и о чем это]
`Z50` – подняться на **50мм выше нуля детали** (безопасная высота).  
*Без G43 команда Z50 означала бы просто "ехать на высоту 50мм от нуля станка", что почти всегда неправильно.*

```cnc
M03 S1600 ;
```
**Запуск шпинделя.**  
`M03` – вращение шпинделя **по часовой стрелке**.  
`S1600` – скорость вращения **1600 оборотов в минуту** (рассчитано по формуле учителя). [Напиши что за формула и как было подсчитано под какой радиус]

```cnc
M08 ;
```
**Включение подачи СОЖ** (смазочно-охлаждающей жидкости). Вода/масло начинает литься на инструмент.

### Проход 1: Верхний слой (Z = -2мм)

```cnc
(--- First pass Z-2 contour 40x20 ---)
```
**Комментарий:** "Первый проход, глубина Z-2, контур 40x20".

```cnc
G00 X-60 Y0 ;
```
**Быстрое перемещение в точку подхода.** Инструмент на безопасной высоте (Z50) быстро летит в точку **X=-60, Y=0** (слева от заготовки).

```cnc
G00 Z-2 ;
```
**Быстрое опускание на глубину резания.** Инструмент опускается прямо до уровня **Z = -2мм** (первый слой). *Внимание: здесь G00, потому что мы уже над пустым местом (X-60), вне материала.*

```cnc
G01 G42 X-20 Y0 D01 F200.0 ;
```
**Рабочая подача с включением компенсации.**  
`G01` – **линейная интерполяция** (движение с рабочей подачей).  
`G42` – включить **правую компенсацию на радиус инструмента**. Станок будет смещать инструмент вправо относительно направления движения на величину, записанную в регистре **D01** (обычно там радиус фрезы = 8мм). Это нужно, чтобы контур получился точно 40x20, а не был шире из-за радиуса фрезы. [Тоже по подробней разъясни]
`X-20 Y0` – целевая точка (начало контура).  
`F200.0` – скорость подачи **200 мм/мин**.

```cnc
G01 X-20 Y-10 ;
```
Движение в точку **X=-20, Y=-10** (левый нижний угол контура).

```cnc
G01 X20 Y-10 ;
```
Движение в точку **X=20, Y=-10** (правый нижний угол).

```cnc
G01 X20 Y10 ;
```
Движение в точку **X=20, Y=10** (правый верхний угол).

```cnc
G01 X-20 Y10 ;
```
Движение в точку **X=-20, Y=10** (левый верхний угол).

```cnc
G01 X-20 Y0 ;
```
Возврат в начальную точку контура **X=-20, Y=0** (замыкаем контур).

```cnc
G00 G40 X-60 Y0 ;
```
**Отмена компенсации и отход.**  
`G40` – **отменить компенсацию на радиус** (дальше инструмент пойдет по заданным координатам, без смещения). [Про компенсации не очень понятно]
`G00` – быстро переместиться обратно в точку подхода **X=-60, Y=0**, чтобы безопасно подняться.

```cnc
G00 Z50 ;
```
**Быстрый подъем на безопасную высоту** (Z=50) перед следующим проходом.

### Проход 2: Z = -4мм (контур 50x30)

```cnc
(--- Second pass Z-4 contour 50x30 ---)
G00 X-60 Y0 ;
G00 Z-4 ;
G01 G42 X-25 Y0 D01 F200.0 ;
G01 X-25 Y-15 ;
G01 X25 Y-15 ;
G01 X25 Y15 ;
G01 X-25 Y15 ;
G01 X-25 Y0 ;
G00 G40 X-60 Y0 ;
G00 Z50 ;
```
**Абсолютно та же логика, что и в первом проходе, но:**
- Глубина: **Z = -4мм**
- Контур больше: от **X=-25 до X=25** (ширина 50мм), от **Y=-15 до Y=15** (высота 30мм)
- Компенсация G42 все еще активна на рабочих ходах

### Проход 3: Z = -6мм (контур 60x40)

```cnc
(--- Third pass Z-6 contour 60x40 ---)
G00 X-60 Y0 ;
G00 Z-6 ;
G01 G42 X-30 Y0 D01 F200.0 ;
G01 X-30 Y-20 ;
G01 X30 Y-20 ;
G01 X30 Y20 ;
G01 X-30 Y20 ;
G01 X-30 Y0 ;
G00 G40 X-60 Y0 ;
G00 Z50 ;
```
Глубина: **Z = -6мм**  
Контур: **60x40** (X от -30 до 30, Y от -20 до 20)

### Проход 4: Z = -8мм (контур 70x50)

```cnc
(--- Fourth pass Z-8 contour 70x50 ---)
G00 X-60 Y0 ;
G00 Z-8 ;
G01 G42 X-35 Y0 D01 F180.0 ;
G01 X-35 Y-25 ;
G01 X35 Y-25 ;
G01 X35 Y25 ;
G01 X-35 Y25 ;
G01 X-35 Y0 ;
G00 G40 X-60 Y0 ;
G00 Z50 ;
```
Глубина: **Z = -8мм**  
Контур: **70x50** (X от -35 до 35, Y от -25 до 25)  
Подача снижена до **F180** (так как снимаем больше материала).

---

### Проход 5: Финишный (Z = -10мм, контур 80x60)

```cnc
(--- Fifth pass Z-10 final contour 80x60 ---)
G00 X-60 Y0 ;
G00 Z-10 ;
G01 G42 X-40 Y0 D01 F150.0 ;
G01 X-40 Y-30 ;
G01 X40 Y-30 ;
G01 X40 Y30 ;
G01 X-40 Y30 ;
G01 X-40 Y0 ;
G00 G40 X-60 Y0 ;
G00 Z50 ;
```
**Финальный проход:**
- Глубина: **Z = -10мм** (заданная глубина детали)
- Контур: **80x60** (полный размер, X от -40 до 40, Y от -30 до 30)
- Подача снижена до **F150** для лучшего качества поверхности (финишная обработка)

### Завершение программы

```cnc
(--- End of program ---)
M05 ;
```
**Остановка шпинделя.**

```cnc
M09 ;
```
**Выключение подачи СОЖ.**

```cnc
G91 G28 Z0 ;
```
**Подъем по Z в "домашнюю" позицию станка** (в относительном режиме). Инструмент уходит наверх, чтобы можно было безопасно снять деталь.

```cnc
M30 ;
```
**Конец программы.** Перемотка в начало и останов.

```cnc
%
```
**Символ конца файла.**

## Таблица основных G-кодов в этой программе

| Код | Значение | Для чего нужен |
|-----|----------|----------------|
| **G00** | Быстрое позиционирование | Перемещение на максимальной скорости (холостые ходы) |
| **G01** | Линейная интерполяция | Рабочее движение с заданной подачей (резание) |
| **G17** | Выбор плоскости XY | Работаем в горизонтальной плоскости |
| **G21** | Метрическая система | Все координаты в миллиметрах |
| **G28** | Возврат в "дом" | Отправить ось в нулевую точку станка |
| **G40** | Отмена компенсации | Выключить смещение на радиус фрезы |
| **G41/G42** | Компенсация радиуса | Смещать инструмент влево (G41) или вправо (G42) на радиус |
| **G43** | Коррекция длины | Учесть длину инструмента (берет значение из H...) |
| **G49** | Отмена коррекции длины | Сбросить коррекцию длины |
| **G54** | Рабочая СК №1 | Выбрать ноль детали, который мы настроили |
| **G90** | Абсолютные координаты | Все координаты от нуля детали |
| **G91** | Относительные координаты | Координаты от текущего положения |

## Таблица M-кодов

| Код | Значение |
|-----|----------|
| **M03** | Включить шпиндель (по часовой) |
| **M05** | Выключить шпиндель |
| **M06** | Смена инструмента |
| **M08** | Включить СОЖ |
| **M09** | Выключить СОЖ |
| **M30** | Конец программы |
