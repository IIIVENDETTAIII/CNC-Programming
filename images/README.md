## 🖼️ Формат изображений

- **Формат:** PNG (для схем), JPG (для фото)
- **Максимальный размер:** 1920x1080px
- **Оптимизация:** используйте сжатие для быстрой загрузки
- **Именование:** английские символы, lowercase, дефисы

## 📝 Как добавить изображение в README

```markdown
![Описание изображения](images/название-файла.png)
```

Пример:
```markdown
![SSCNC Simulator Example](images/sscnc-simulator-example.png)
```
