1] Tools Configuration File.ct

	Setting > Machine Operation > Tool Management > Load Tool Info File

	Что это: Файл конфигурации инструментов (резцов, сверл, фрез).

	За что отвечает: Содержит базу данных инструментов, которые ты настроил в текущей симуляции: их номера (T1, T2), геометрию (радиус, длина), корректоры, типы 	(черновая/чистовая фреза, сверло) и материал.


2] Workpiece Configuration File.wp

	Setting > Workpiece Stock Size and WCS > Load Workpiece file

	Что это: Файл конфигурации заготовки и приспособлений.

	За что отвечает: Сохраняет параметры твоей "болванки": из какого она материала, её размеры (X, Y, Z), положение нуля (детали) на столе, а также параметры тисков, 	прижимов и другой оснастки, которую ты установил.


3] NC Code Files txt
	
	Что это: Файлы Управляющей программы (G-code).

	За что отвечает: Это сам код, который станок будет исполнять (строчки типа G00 X0 Y0, G01 Z-5 F100 и т.д.). Ты мог либо загрузить готовый файл, либо написать его в 	редакторе симулятора.


4] Project Files
	
	Что это: Полный проект (самое важное!).

	За что отвечает: Сохраняет ВСЁ СРАЗУ:

	Текущий G-code (код программы)

	Настройки инструментов

	Параметры заготовки

	Положение модели и детали на столе

	Состояние симуляции (если ты что-то уже обработал)


5] Binary Project Files
	
	Что это: Бинарный (двоичный) файл проекта.

	В чем разница: Обычные Project Files могут сохраняться в текстовом формате (чтобы можно было открыть блокнотом и посмотреть настройки). Binary Project Files сохраняет 	то же самое, но в сжатом, "машинном" формате.

	Зачем нужно: Такой файл обычно весит меньше и быстрее загружается/сохраняется, особенно если симуляция сложная. Однако его нельзя отредактировать в стороннем 	текстовом редакторе — только через сам симулятор.
