PART 1: MACHINE COORDINATE SYSTEMS & OFFSET THEORY
====================================================================

1.1 FUNDAMENTAL CONCEPTS: MCS vs WCS
Every CNC machine has two coordinate systems:

MACHINE COORDINATE SYSTEM (MCS): Fixed zero point built into the machine hardware. All machine movements reference this point. Cannot be changed without recalibrating the machine.

WORK COORDINATE SYSTEM (WCS): Set by the operator to match the workpiece position. Different for each workpiece or feature. Multiple WCS can be stored (G54-G59).

WORK OFFSET: The distance between MCS zero and WCS zero. Stored in offset tables and automatically applied when you call the WCS code (G54, G55, etc.)

PRACTICAL IMPLICATION: When you program G54 X0 Y0, the machine doesn't move to machine zero. It moves to the position stored in the G54 offset table. This separation allows one program to work with multiple parts without modification.

---

1.2 SETTING WORK OFFSETS - EDGE FINDER METHOD
EQUIPMENT: Edge Finder with 6mm diameter eccentric tip. Typical measuring tool in all CNC shops.

PROCEDURE FOR X-AXIS:
1. Mount Edge Finder in spindle
2. Rotate spindle at 500-750 RPM (IMPORTANT: slow speed prevents tool damage)
3. Touch Edge Finder to workpiece edge
4. When wobbling stops and tip aligns with spindle center, record the X value on machine display
5. Move 3mm in (subtract 3mm to account for 6mm tool diameter)
6. Move tool to exact zero position
7. Press "Part Zero Set" button or "Pot Zero" (sets offset value)
8. Record the offset value automatically stored in offset table

РУССКИЙ (RUSSIAN):
ОБОРУДОВАНИЕ: Поиск кромок с диаметром эксцентричного наконечника 6 мм. Типичный измерительный инструмент во всех цехах ЧПУ.

ПРОЦЕДУРА ДЛЯ ОСИ X:
1. Смонтируйте поиск кромок в шпиндель
2. Вращайте шпиндель на 500-750 об/мин (ВАЖНО: медленная скорость предотвращает повреждение инструмента)
3. Коснитесь поиска кромок к кромке заготовки
4. Когда колебание останавливается и наконечник совпадает с центром шпинделя, запишите значение X на дисплее станка
5. Переместитесь на 3 мм (вычтите 3 мм, чтобы учесть диаметр инструмента 6 мм)
6. Переместите инструмент к точной нулевой позиции
7. Нажмите кнопку "Part Zero Set" или "Pot Zero" (устанавливает значение смещения)
8. Запишите значение смещения, автоматически сохраненное в таблице смещения

---

1.3 ALTERNATIVE: DIAL TEST INDICATOR (DTI) METHOD
ADVANTAGE: No manual offset calculation needed. DTI shows exact dimension directly.
BEST FOR: Finding center points of circular features, checking perpendicularity
LIMITATION: Slower than edge finder, requires careful reading of dial

DTI provides most accurate results for circular work because you can measure directly without the 3mm compensation needed with edge finder.

---

1.4 FINDING THE CENTER POINT
If you want WCS origin at the center of the workpiece:

EDGE FINDER METHOD:
1. Touch X-axis one side: Record value (e.g., 106.4)
2. Touch X-axis opposite side: Record value (e.g., 53.2)
3. Divide first value by 2: 106.4 ÷ 2 = 53.2 (center point)
4. Move to that position and set offset
5. Repeat for Y-axis

ADVANTAGE: Center origin simplifies programming because all coordinates are centered
DISADVANTAGE: Takes extra steps compared to corner origin

---

1.5 PERPENDICULARITY CHALLENGES
REALITY: Workpiece surfaces often vary due to manufacturing tolerance
TOLERANCE EXAMPLE: ±0.5mm on each side means surfaces might not be perfectly parallel
SOLUTION: Keep Y-offset the same on both sides even if they measure differently
RESULT: Center point is automatically correct due to symmetrical positioning

USE SIX SQUARE: Precision square tool to verify perpendicularity before setting offsets

---

1.6 WORK OFFSET CODES (G54-G59)
G54 - Primary offset (default, most common)
G55 - Secondary offset
G56 - Third offset
G57 - Fourth offset
G58 - Fifth offset
G59 - Sixth offset

PROGRAMMING EXAMPLE:
... cuts feature at first position using G54 ...
G55 (Switch offset)
... cuts feature at second position ...

This allows multiple features on same workpiece to be programmed without re-offsetting

PART 2: CNC SPEEDS, FEEDS & CUTTING CALCULATIONS
====================================================================

2.1 SPINDLE SPEED CALCULATION
FORMULA: N = (Vc × 1000) / (π × D)

WHERE:
N = Spindle Speed (RPM)
Vc = Cutting Speed (meters per minute) - material dependent
D = Tool Diameter (millimeters)
π = 3.14159
1000 = conversion factor

EXAMPLE CALCULATION:
Material: Aluminum (Vc = 300 m/min)
Tool: 10mm diameter
Calculation: N = (300 × 1000) / (3.14159 × 10) = 9,549 RPM ≈ 9,500 RPM

---

2.2 CUTTING SPEED (Vc) VALUES BY MATERIAL
Aluminum: 250-400 m/min (fastest, easily machinable)
Brass: 200-250 m/min
Mild Steel: 100-200 m/min
Cast Iron: 80-150 m/min (slow, difficult)
Stainless Steel: 80-150 m/min (generates heat)
Plastics: 150-300 m/min (varies by type)

SOURCE: Obtained from material suppliers, machining handbooks, tool manufacturers
IMPORTANCE: Using correct Vc prevents tool breakage, overheating, and poor finishes

---

2.3 FEED RATE CALCULATION
FORMULA: F = N × Z × FPT

WHERE:
F = Feed Rate (mm/min or inches/min)
N = Spindle Speed (RPM)
Z = Number of Flutes (cutting edges)
FPT = Feed Per Tooth (mm/tooth) - depends on material and tool

TYPICAL FPT VALUES:
Small diameter tools (1-5mm): 0.05-0.1 mm/tooth
Medium tools (5-10mm): 0.1-0.15 mm/tooth
Large tools (10mm+): 0.15-0.2 mm/tooth

EXAMPLE:
Spindle Speed: 9,500 RPM
Flutes: 2 (slot drill)
FPT: 0.1 mm/tooth
Feed = 9,500 × 2 × 0.1 = 1,900 mm/min

---

2.4 EFFECT OF NUMBER OF FLUTES
2-FLUTE TOOL:
- Lower feed rate but large gap between teeth allows chip clearance
- MUST use for plunging (cutting straight down)
- Lower productivity but safer for restricted movements

3-FLUTE TOOL:
- Medium feed rate
- Better for side milling and face milling
- Good chip flow

4-FLUTE TOOL:
- Highest feed rate (1.33× higher than 2-flute)
- Smooth cutting, excellent surface finish
- Cannot plunge directly without special helical motion

COMPARISON (same speed/FPT):
2-flute: F = 1,900 mm/min
3-flute: F = 2,850 mm/min (1.5× faster)
4-flute: F = 3,800 mm/min (2× faster)

---

2.5 MATERIAL REMOVAL RATE (MRR)
MRR = Axial Depth × Radial Depth × Feed Rate

PRACTICAL MEANING: Volume of material removed per minute
DETERMINES: Production speed and job cycle time

TO INCREASE PRODUCTIVITY:
1. Increase feed rate (if tool allows)
2. Increase depth of cut (tool and machine must withstand increased force)
3. Select proper tool for material
4. Optimize spindle speed

BALANCE REQUIRED: Speed vs. tool life vs. surface quality

---

2.6 TOOL COATINGS & IMPROVEMENTS
TITANIUM NITRIDE (TiN): Golden color, reduces friction, 10-20% faster speeds, suitable for steel
TITANIUM ALUMINUM NITRIDE (TiAlN): Even harder, high cutting speeds, difficult materials
COBALT ADDITIONS: Increased toughness, longer tool life for tough materials

BENEFIT: Coated tools can operate 10-20% faster than uncoated tools
TRADE-OFF: More expensive but extends intervals between tool changes
REQUIREMENT: Quality coolant still essential for all tools

---

2.7 CUTTING SPEED VARIATIONS BY OPERATION
FACING (flat surface): 1200-1500 RPM (example: 50mm face mill on steel)
SHOULDER/SIDE CUTTING: 1500-1800 RPM (unrestricted chip flow)
SLOTTING (internal slots): Reduce speed 5-10% due to poor chip clearance
POCKET MILLING: Medium speeds, depends on pocket configuration

KEY PRINCIPLE: Any restricted chip flow = reduce speed 5-10% from unobstructed cutting

3.2 SAFETY STARTUP CODES EXPLAINED
G17: Select XY plane (default working plane for most jobs)
G20: Inch units (alternative: G21 for metric mm)
G40: Cancel diameter compensation (IMPORTANT: prevents old compensation from interfering)
G49: Cancel tool length compensation
G80: Cancel canned cycles (CRITICAL: prevents unexpected automatic movements)
G90: Absolute positioning mode (coordinates are absolute, not relative)

SEQUENCE: These should appear together at start of program

RUSSIAN: КОДЫ БЕЗОПАСНОГО ЗАПУСКА ОБЪЯСНЕНЫ
G17: выбрать плоскость XY (плоскость по умолчанию для большинства работ)
G20: дюймовые единицы (альтернатива: G21 для метрических мм)
G40: отменить компенсацию диаметра (ВАЖНО: предотвращает помехи со старой компенсацией)
G49: отменить компенсацию длины инструмента
G80: отменить все запрограммированные циклы (КРИТИЧЕСКИЙ: предотвращает неожиданные автоматические движения)
G90: режим абсолютного позиционирования (координаты абсолютные, не относительные)

ПОСЛЕДОВАТЕЛЬНОСТЬ: К ним должны появляться вместе в начале программы

---

3.3 MOVEMENT G-CODES
G00 (RAPID MOVE): Fastest possible speed, non-cutting only
SYNTAX: G00 X10 Y20 Z-5 (moves to these coordinates at high speed)
USE: Getting to cutting positions, tool changes, moving away from work

G01 (LINEAR MOVE): Straight line at controlled feed rate, used for cutting
SYNTAX: G01 X10 Y20 Z-5 F100 (moves in straight line at 100 mm/min)
USE: All actual cutting operations

G02 (ARC CLOCKWISE): Circular motion clockwise with specified radius
SYNTAX: G02 X20 Y20 R10 (arc with 10mm radius, ending at X20 Y20)
Alternative: G02 X20 Y20 I5 J5 (center point offset I5 from start, J5 from start)

G03 (ARC COUNTER-CLOCKWISE): Circular motion counter-clockwise
SYNTAX: G03 X20 Y20 R10
USE: Cutting circular features like pockets, indents, rounded edges

---

3.4 SPINDLE & COOLANT CODES
S1200: Set spindle speed to 1200 RPM (replace 1200 with desired speed)
IMPORTANT: Must come before M03/M04 to take effect

M03: Start spindle CLOCKWISE (normal cutting direction)
M04: Start spindle COUNTER-CLOCKWISE (used rarely)
M05: Stop spindle

M08: Coolant ON (flood coolant typical)
M09: Coolant OFF

TYPICAL SEQUENCE:
S1200 M03 (Start spindle at 1200 RPM before cutting)
G01 X10 Y20 Z-5 F100 (Cut while spindle turns)
M09 (Stop coolant when done cutting)
M05 (Stop spindle after cutting)

DO NOT: Start cutting before spindle is running
DO NOT: Stop spindle while cutting (tool may break)

---

3.5 TOOL & OFFSET SELECTION
T01: Select tool number 1 (T01, T02, T03, ... etc.)
FUNCTION: Tells machine which tool to use
EFFECT: Machine moves to tool changer, selects tool, brings to spindle
TIMING: Usually done during tool changes

H01: Tool height offset number 1 (applied with G43)
FUNCTION: Compensates for different tool lengths
SYNTAX: H01 G43 (Apply offset 1)
IMPORTANCE: Without H offset, tool cuts at wrong height

G54: Work offset 54 (G54, G55, G56, G57, G58, G59)
FUNCTION: Sets zero point for workpiece
SYNTAX: G54 X0 Y0 (Move to origin of offset 54)
MULTIPLE OFFSETS: One program can use multiple offsets for different features

EXAMPLE SEQUENCE:
T01 (Select tool 1)
G54 (Select work offset 54)
G00 Z50 (Rapid to 50mm above work)
H01 G43 (Apply tool offset 1)
[Cuts using offset 54]
T02 (Select tool 2)
G55 (Switch to offset 55)
H02 G43 (Apply tool offset 2)
[Cuts using offset 55]

---

3.6 TOOL LENGTH COMPENSATION (H codes and G43)
PROBLEM: Different tools have different lengths. Without compensation, tool cuts at different heights.

SOLUTION: H offset codes and G43 enable compensation
SYNTAX: H01 G43 (Apply height offset 1)

EXPLANATION:
- Each tool has a measured height stored in offset table
- H01 references offset 1, H02 references offset 2, etc.
- G43 tells machine to apply the compensation
- When moving Z axis, compensation is automatically calculated
- Tool always cuts at correct height regardless of physical tool length

CRITICAL: Must apply H offset and G43 before any Z movement with that tool
SEQUENCE: H01 G43 Z50 (Apply offset, then move to safety height)

---

3.7 PROGRAM END
M02: Program end (older standard)
M30: Program end with reset (modern standard)

FUNCTION: Ends program, stops spindle, turns off coolant, resets all modes
PLACEMENT: Always last line of program
EXAMPLE:
G00 Z100 (Final move to safety)
M09 (Coolant off)
M05 (Spindle off)
M30 (Program end - this is the last line)

PART 4: MACHINE SETUP & OPERATION
====================================================================

4.1 CNC MACHINE AXES EXPLAINED
X-AXIS: Horizontal left-right motion (viewing machine from operator's side)
Y-AXIS: Horizontal front-back motion (depth)
Z-AXIS: Vertical up-down motion (height, most critical for safety)

POSITIVE DIRECTIONS:
X+: Usually right
Y+: Usually away from operator (toward back)
Z+: Usually upward (toward spindle)

WORKSPACE ENVELOPE: Maximum travel limits in all directions
IMPORTANCE: Must understand limits to avoid crashing machine
CHECK BEFORE: Every new program on unfamiliar machine

---

4.2 WORK HOLDING DEVICES
VICE (most common): Machine vice with clamping surfaces
HOW TO USE: Clamp workpiece securely, ensure surfaces are parallel
FORCE: Use moderate to firm pressure - enough to hold, not excessive

CLAMPS: Alternative for irregular shapes
STEP BLOCKS: Used with clamps to support work at correct height
MAGNETIC CHUCK: For ferrous (iron-based) materials only

CRITICAL: Workpiece must not move during machining
VERIFICATION: Try to move workpiece by hand before starting program

---

4.3 MACHINE POWER-UP PROCEDURE
1. Switch on main power
2. Wait for system boot (control panel displays coming to life)
3. Clear any alarm messages (press reset button)
4. Home each axis if machine is offline:
   - Move Z axis to home first
   - Then move X and Y axes
   - Press cycle start or use manual override buttons

5. Load workpiece in vice
6. Set work offset using edge finder
7. Check tool is in spindle (usually T0 = no tool initially)

---

4.4 SETUP: STOCK SIZING & WCS LOCATION
In simulator or setup menu:
1. Define stock dimensions (X length, Y width, Z height)
2. Define WCS location (top face usually)
3. Define vice height and tool clearance (minimum 5mm necessary)

PRACTICAL: Extra material needed for vice holding
Example: 5mm in vice, 15mm available for cutting (from 20mm total height)

---

PART 5: CUTTING TOOLS & TOOL MANAGEMENT
====================================================================

5.1 TOOL NOMENCLATURE & PARTS
SHANK (SANK): Top portion inserted into tool holder - NOT used for cutting
- Standard diameters match collet sizes
- Held tight in spindle by collet
- Modern collet less shank available

CUTTING PORTION: Lower section with cutting flutes (teeth)
FLUTES: Spiral edges that actually cut the material

CUTTING LENGTH: Distance from cutting edge to start of shank
FLUTE LENGTH: Including the clear relief portion
OVERALL LENGTH: Total from tip to top of shank

HELIX ANGLE: Spiral angle of flutes
- 45°-60° typical: Standard for general milling
- Steeper helix: Better chip evacuation for roughing
- Shallow helix: Less aggressive, smoother finish

---

5.2 END MILL vs SPOT DRILL vs SPECIAL TOOLS
END MILL (N-Mill): Most common tool
- Cutting diameter equals shank diameter
- Can cut in X, Y, and Z directions
- 2, 3, or 4 flutes available
- Can side mill and plunge with proper selection

SLOT DRILL: Special 2-flute end mill
- MUST use for plunging (cutting straight down)
- Large gap between teeth allows chip removal
- Cannot use 3+ flute tools for direct plunging

SPOT DRILL: Small carbide tool for center marking
- Creates small depression for drill to follow
- Prevents drill wandering on initial contact
- Used before drilling holes

BALL NOSE: Spherical cutting surface
- For curved 3D surfaces
- Cannot make sharp inside corners
- Lower productivity

---

5.3 RADIAL & AXIAL DEPTH OF CUT
AXIAL DEPTH (Z depth): How deep tool goes in Z direction (vertically)
- Limited by cutting length of tool
- Too deep: Tool breaks or can't fit in pocket
- Typical: 1-10mm per pass depending on material

RADIAL DEPTH (step over): How much tool removes moving in X or Y
- Limited by tool strength and machine power
- Too large: Tool breaks or deflection causes poor finish
- Typical: 1-5mm for small tools in aluminum

CONSTRAINT: Cannot exceed cutting length in Z direction
EXAMPLE: 10mm cutting tool can only go 10mm deep maximum

---

5.4 MULTI-PASS ROUGHING STRATEGY
PROBLEM: Cannot remove 20mm depth in one pass with 10mm cutting length tool

SOLUTION: Make multiple passes:
Pass 1: G01 Z-5 (Remove 5mm)
Pass 2: G01 Z-10 (Remove another 5mm)
Pass 3: G01 Z-15 (Remove another 5mm)
Pass 4: G01 Z-20 (Remove final 5mm)

EFFICIENCY: Can also move in XY direction during roughing
Move 1-2mm in XY, move 5-10mm in Z per pass

---

6.1 SIMULATOR SOFTWARE BASICS

- NO RISK: Safe to crash and experiment

1. Visual check: Does tool path match drawing?
2. Depth check: Is final depth correct?
3. Dimensions check: Are cut dimensions correct?
4. Clearance check: Does tool avoid clamps, vice?
5. Speed/feed check: Are RPM and feed rates reasonable?
6. Offset check: Was correct offset used?

ONLY after simulator verification, run on real machine

PART 7: INSIDE & OUTSIDE CUTTING (G41 & G42)
====================================================================

7.1 CUTTER COMPENSATION CODES
G40: Cancel cutter diameter compensation (default state)
G41: Offset left (for inside cutting patterns)
G42: Offset right (for outside cutting patterns)

PROBLEM: Tool diameter means actual cut position is away from programmed path
- 10mm diameter tool cutting a 100mm profile
- If you program exact 100mm path, bottom edge of tool misses target
- Tool creates 110mm cut, not 100mm

SOLUTION: Use G41/G42 to automatically offset tool path

---

7.2 OUTSIDE CUTTING PATTERN (G42)
PROFILE: Cutting the outside edge of a component
EXAMPLE: Making rectangular part from larger stock

PROGRAMMING:
G42 (Activate right offset)
G01 X0 Y0 F100
G01 X30 Y0 (Cuts right edge, tool automatically offset right)
G01 X30 Y40 (Cuts top edge)
G01 X0 Y40 (Cuts left edge)
G01 X0 Y0 (Cuts bottom edge back to start)
G40 (Cancel compensation)

TOOL MOVEMENT: Tool traces path OUTSIDE the programmed profile
RESULT: Actual cut matches programmed dimensions exactly

---

7.3 INSIDE CUTTING PATTERN (G41)
PROFILE: Cutting a pocket or hole inside material
EXAMPLE: Square hole in center of plate

PROGRAMMING:
G41 (Activate left offset)
G01 X10 Y10 F100
G01 X40 Y10 (Tool automatically offset left for inside cut)
G01 X40 Y40
G01 X10 Y40
G01 X10 Y10
G40 (Cancel compensation)

TOOL MOVEMENT: Tool traces path INSIDE the programmed profile
RESULT: Pocket matches programmed dimensions

---

7.4 RADIUS COMPENSATION DETAILS
FORMULA HANDLED BY MACHINE: Machine automatically calculates tool offset = tool radius
- 10mm diameter tool radius = 5mm
- G42 (outside): Tool path moves right 5mm from programmed path
- G41 (inside): Tool path moves left 5mm from programmed path

APPROACH: Program the exact outline dimension, compensation does the rest

PART 8: SUB-PROGRAMS & PROGRAM MANAGEMENT
====================================================================

8.1 REPETITIVE CUTTING - SUB-PROGRAM APPROACH
PROBLEM: Cut same pattern 20 times = 20 × 50 lines of code = 1000 lines

SOLUTION: Write sub-program once, call it multiple times

MAIN PROGRAM:
O00001
[Setup code ...]
G91 G28 Z0 (Home Z)
G90 G00 X0 Y0 (Go to first position)
Z50 H01 G43 (Offset height)
S1200 M03 (Start spindle)
[Prepare for cutting]
M98 P22 L20 (Call program 22 repetition 20 times)
[Cleanup code ...]
M30 (End)

SUB-PROGRAM:
O00022
[Single cutting pattern = 50 lines]
M99 (End sub-program, return to main)

ADVANTAGE: 700 lines instead of 1000
MAINTAINABILITY: Change pattern once in sub-program, all 20 copies updated automatically

---

8.2 M98 & M99 CODES
M98: Call sub-program
SYNTAX: M98 P22 L20
- P22: Program number to call (02-99, L prefix on some machines)
- L20: Number of repetitions (1-9999)
- Example: M98 P22 L20 = call program 22, repeat 20 times

M99: End sub-program and return to main
PLACEMENT: Last line of sub-program
EFFECT: Control returns to line after M98 in main program

---

8.3 PROGRAM NUMBERING STRATEGY
NAMING CONVENTION: O followed by 1-5 digits
O00001 (5 digits, leading zeros)
O1 (1 digit, no leading zeros)
O0001 (4 digits)

ORGANIZATION EXAMPLE:
O00100-O00199: Part family A
O00200-O00299: Part family B
O00001-O00099: Sub-programs

DOCUMENTATION: Always comment program numbers
; Main program 00123
; Sub-programs: 01, 02, 03

---

8.4 PROGRAM STORAGE & MANAGEMENT
MEMORY: Limited machine memory (varies by machine)
USB STORAGE: Portable programs on USB stick
FILE NAMING: Match program number to actual file name
BACKUP: Always keep backup copies of proven programs

WORKFLOW:
1. Write program on computer
2. Test in simulator
3. Save to USB
4. Transfer to machine memory
5. Run on machine with approval
6. Keep successful programs for future reference

PART 9: SAFE MACHINE OPERATION & HAZARDS
====================================================================

9.1 CRITICAL SAFETY FEATURES
EMERGENCY STOP BUTTON: RED button, always accessible
- Stops all motion immediately
- Disables spindle
- Disables coolant
- USE: Any time danger is perceived
- MUSCLE MEMORY: Practice finding it without looking

DOOR INTERLOCK: Door must be closed for many operations
- Some setup operations allowed with door open (manual movements)
- Spindle starts only with door closed (on most machines)
- NEVER: Insert hands while spindle running

---

9.2 COMMON HAZARDS
ROTATING SPINDLE: Catches hair, loose clothing, hands
SOLUTION: Long hair tied back, no loose sleeves, never reach toward spindle while running

HOT CUTTERS: Cutting generates heat
SOLUTION: Let tool cool before touching, use brush to clear chips not bare hands

FLYING CHIPS: Small metal pieces ejected at high speed
SOLUTION: Safety glasses mandatory, keep face back from work

NOISE: Sustained noise can cause hearing damage
SOLUTION: Hearing protection if 70+ decibels

CONFINED WORKSPACE: Limited clearance in vice area
SOLUTION: Clear path for emergency movement, nothing blocking emergency stop access

---

9.3 PRE-OPERATION CHECKLIST
Before running any program:
☐ Tool is correct for job
☐ Work offset has been set and verified
☐ Spindle speed is safe for material and tool size
☐ Feed rate is reasonable
☐ Tool clears all clamps and vice edges
☐ Z-depth doesn't exceed cutting tool length
☐ Workpiece is secure in vice
☐ Coolant is filled and flowing
☐ All unnecessary items cleared from machine
☐ Door is closed
☐ Safety glasses on
☐ Hair tied back

---

9.4 OPERATION SEQUENCE
1. Load workpiece
2. Set offsets (X, Y, Z)
3. Verify offsets by checking tool position with paper test
4. Temporarily set Z offset to safe height (Z-50 or Z-100)
5. Run one pass in single-block mode (one line at a time)
6. At Z-50, STOP and verify tool is above work
7. Replace paper, press continue
8. Now tool cuts actual depth
9. Monitor carefully first few moves
10. If correct, can run remaining program in continuous mode

PART 11: MANUAL HANDLING & ERGONOMICS
====================================================================

11.1 MANUAL HANDLING DEFINITION & IMPORTANCE
MANUAL HANDLING: Any activity involving lifting, carrying, pushing, pulling, or moving loads by hand or body

STATISTICS: Over 30% of workplace injuries relate to manual handling
MOST AFFECTED: Lower back (90% of injuries), shoulders, knees, wrists

PREVENTION: Costs far less than treatment and lost work time
INDIVIDUAL RESPONSIBILITY: Each person must protect their own health through proper technique

---

11.2 SPINE ANATOMY & VULNERABILITY
CERVICAL (C1-C7): Neck - 8% of injuries (relatively strong, protected by muscles)
THORACIC (T1-T12): Mid-back - 2% of injuries (protected by ribs, minimal flexing)
LUMBAR (L1-L5): Lower back - 90% of injuries (most vulnerable, bears weight, most flexing)
SACRUM & COCCYX: Tail bones - fused, no shock absorbers

KEY ISSUE: Most bending and loading on lower back causes cumulative damage

---

11.3 THE DISC STRUCTURE
ANNULUS: Outer ring of tough fibrous material
NUCLEUS: Inner gel-like substance that absorbs shock and allows flexibility
POOR BLOOD SUPPLY: Discs must get nutrition from diffusion (movement) and hydration (water)

INJURY MECHANISM: Repeated bending, twisting, or heavy lifting causes micro-trauma
MICRO-DAMAGE: Small tears accumulate over time
DISC HERNIATION: Nucleus bulges through damaged annulus, pressing on nerve causing pain

---

11.4 PROPER LIFTING TECHNIQUE - THE 10 CRITICAL POINTS
1. ASSESS THE LOAD: Weight, shape, grip handles?
2. PLAN THE MOVE: Know route, check for obstacles
3. POSITION YOURSELF: Feet shoulder-width apart, one slightly forward
4. SQUAT, DON'T BEND: Bend knees, keep back straight
5. SECURE GRIP: Firm, balanced grip with both hands
6. ELBOWS IN: Keep elbows close to body
7. ENGAGE CORE: Tighten abdominal muscles
8. LIFT BY LEGS: Use powerful leg muscles, not back
9. KEEP LOAD CLOSE: Closer to body = less back strain
10. TURN WITH FEET: Don't twist at waist, move feet instead

RUSSIAN: ПРАВИЛЬНАЯ ТЕХНИКА ПОДНЯТИЯ - 10 КРИТИЧЕСКИХ ТОЧЕК
1. ОЦЕНИТЕ НА ГРУЗ: вес, форма, ручки для захвата?
2. ПЛАНИРУЕТЕ ДВИЖЕНИЕ: знаешь маршрут, проверить препятствия?
3. ПОЗИЦИЯ СЕБЯ: ноги на ширине плеч, одна слегка вперед
4. ПРИСЯДЬТЕ, НЕ СГИБАЕТЕСЬ: согните колени, держите спину прямой
5. БЕЗОПАСНЫЙ ЗАХВАТ: Крепкий, сбалансированный захват обеими руками
6. ЛОКТИ ВНУТРИ: Держите локти близко к телу
7. ВКЛЮЧИТЬ ЯДРО: Затяните мышцы живота
8. ПОДНЯТЬ ПО НОГАМ: Используйте мощные мышцы ног, не спину
9. ДЕРЖАТЬ ГРУЗ БЛИЗКО: Ближе к телу = меньше напряжения на спину
10. ПОВОРОТ С НОГАМИ: Не крутите талией, двигайте ногами

---

11.5 ERGONOMICS AT WORKSTATION
SITTING: Sit fully back in chair, feet flat on ground, monitor at eye level
- Avoid hunching forward
- Avoid legs crossed or tucked under
- Use back support if available

STANDING: Weight evenly distributed, knees slightly bent, shoulders relaxed
- Avoid leaning to one side
- Avoid prolonged static posture
- Change position frequently

SCREEN TIME:
- Take breaks every 30-45 minutes
- Look at distant objects to rest eyes
- Adjust monitor distance to arm's length away
- Top of monitor at eye level

---

11.6 PREVENTION STRATEGIES
INDIVIDUAL RESPONSIBILITY:
- Use mechanical aids (trolley, dolly, hoist) before lifting manually
- Ask for help when needed - no shame in that
- Maintain fitness and flexibility
- Stay hydrated and well-fed (disc nutrition comes from body)
- Report pain early before it becomes serious

ORGANIZATIONAL RESPONSIBILITY:
- Provide mechanical lifting aids
- Ensure pathways clear of obstacles
- Limit load weight (20kg maximum recommended)
- Train proper technique regularly (refresh every 3 years)
- Assess workstation ergonomics

LONG-TERM HEALTH:
At age 40, your body depends on what you did in your 20s and 30s
At age 70, you'll depend on what you did in your 40s and 50s
Prevention now = healthy, active life later

SUMMARY OF CRITICAL FORMULAS & CODES
====================================================================

SPINDLE SPEED: N = (Vc × 1000) / (π × D)
FEED RATE: F = N × Z × FPT
MATERIAL REMOVAL RATE: MRR = Axial Depth × Radial Depth × Feed Rate

MOVEMENT CODES:
G00 = Rapid (fastest, non-cutting)
G01 = Linear (controlled feed, cutting)
G02 = Arc clockwise
G03 = Arc counter-clockwise

SAFETY CODES:
G17 = XY plane
G20 = Inches (or G21 = metric)
G40 = Cancel diameter offset
G90 = Absolute positioning

OFFSETS:
G54-G59 = Work offsets
H01-H99 = Tool height offsets

SPINDLE & COOLANT:
S1200 = Set speed to 1200 RPM
M03 = Start spindle CW
M05 = Stop spindle
M08 = Coolant ON
M09 = Coolant OFF

PROGRAM CONTROL:
M98 P22 L20 = Call program 22, repeat 20 times
M99 = End sub-program
M30 = Program end

COMPENSATION:
G41 = Offset left (inside cuts)
G42 = Offset right (outside cuts)
